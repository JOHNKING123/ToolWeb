使用说明

解码：文件经 FileReader 读入 ArrayBuffer 后，用 Web Audio API 的 decodeAudioData 在浏览器本地解码为 AudioBuffer（MP3/WAV/OGG/M4A/AAC 是否支持取决于浏览器解码器）。
变速：滑块 0.5x–1.5x（超出自动钳制），或点一键预设：0.8x Slowed / 1.0x 正常 / 1.25x Nightcore。实现为 playbackRate，音调随速度自然变化。
混响：四选一脉冲响应预设 —— 怀旧磁带（Nostalgic）/ 空灵氛围（Ambient）/ 深邃房间（Deep Room）/ 柔和回声（Soft Echo，带离散回声抽头）。脉冲响应由确定性随机算法程序化合成（同一预设每次结果一致），经 ConvolverNode 卷积；混响量滑块控制干湿比（等功率淡化）。
渲染：OfflineAudioContext 离线渲染整轨，进度条分段更新；渲染结果 = 变速后主干时长 ＋ 混响尾音。
试听：A/B 对比 —— 「播放原音频」与「播放效果」一键切换，确认满意再导出。
导出：WAV 为手工编码的 16-bit PCM（44 字节标准头）；MP3 经本地 lamejs 编码（重采样到 44100Hz，128/192/320kbps 可选，长音频分块编码不卡死页面）。
隐私：全程无网络请求 —— 上传、解码、渲染、试听、编码、下载都在你的浏览器里完成，可在 DevTools Network 面板验证；刷新页面后音频不恢复。

❓ 常见问题

音频会被上传到服务器吗？
不会。所有步骤（上传读取、解码、变速、混响渲染、A/B 试听、WAV/MP3 编码、下载）都在你的浏览器本地完成，脚本内零 fetch/XHR。你可以在开发者工具的 Network 面板验证：上传音频后没有任何网络请求发出。刷新页面后音频不恢复。
Slowed 和 Nightcore 是什么？
都是变速听歌的流行玩法：0.8x Slowed 把歌放慢并降调，配上混响就是经典的 slowed+reverb 味；1.25x Nightcore 加速并升调，元气满满。本工具一键预设这两个速度，也可以用滑块在 0.5x–1.5x 间自由调节。
四个混响预设有什么区别？
怀旧磁带（Nostalgic）：温暖老旧磁带感，中长尾音，最适合 slowed；空灵氛围（Ambient）：超长尾音，空间感开阔；深邃房间（Deep Room）：尾音短促集中，闷而深；柔和回声（Soft Echo）：带离散回声抽头，余音有节奏地渐弱。
混响量调到 0% 会怎样？
等于纯变速：干声直通、湿声关闭，渲染结果就是单纯变速后的音频，时长 = 原时长 ÷ 变速比（如 1.25x 下约原时长的 80%）。
渲染后的时长为什么比变速后的长一点？
因为包含了混响尾音。渲染总时长 = 变速后主干时长 ＋ 该预设脉冲响应的时长（如怀旧磁带约 2 秒）。想要精确卡时长可以再用音频裁剪器修一下尾巴。
导出的 MP3 时长和 WAV 一致吗？
一致。两者都来自同一份离线渲染结果，只是编码格式不同（WAV 无损体积大，MP3 有损体积小）。比特率越高 MP3 体积越大、音质越好。
导出的文件叫什么名字？
自动命名为「原文件名_slowed-{速度}x_reverb-{混响量}.扩展名」，例如 夜曲_slowed-0.8x_reverb-50.mp3；混响量为 0% 时省略 reverb 段。如需其他名字，下载后重命名即可。
