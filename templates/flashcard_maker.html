🃏 闪卡卡片生成器

抽认卡背单词/记知识点：卡组管理 → 翻转练习 → 认识/不认识判定 → 间隔重复复习，纯本地不登录

① 卡组管理

点击卡组切换当前练习卡组；每张卡组右下角可重命名、导出 JSON、删除。

② 掌握进度

新卡＝从未复习；学习中＝复习过但间隔 <7 天；已掌握＝间隔 ≥7 天；今日待复习＝已到复习时间的卡片数。

③ 翻转练习

先自己回忆答案，再点击卡片或按空格键翻转核对；翻面后点「认识 ✓」/「不认识」，进入简化 SM-2 间隔重复调度。

④ 卡片编辑 · 卡片编辑

批量导入：每行一张卡，格式为「正面 + Tab + 反面」（也兼容用 | 分隔）。

⑤ 导入 / 导出 JSON

导出文件形如 flashcards_20261103_030000.json，格式为 {"name":"卡组名","cards":[{"front":"正面","back":"反面"}]}，换设备/换浏览器时靠它迁移；导入会新建一个卡组（原有卡组不受影响）。

真限制（先说清楚）

  • ① 只存本浏览器：卡组存在 localStorage 里，跨设备不同步；清除浏览器数据/换浏览器/重装系统都会丢失——重要卡组请定期导出 JSON 备份。
  • ② 简化版 SM-2：复习调度是「认识/不认识」二元判定的简化版 SM-2（间隔=ceil(间隔×ease)，认识 ease+0.1，不认识 ease-0.2 且下限 1.3），不是完整的 SuperMemo 算法，复习节奏仅供参考。
  • ③ 纯本地处理：卡组内容只在你的浏览器内流转，不会上传到任何服务器（可在浏览器 Network 面板自证）。

使用说明

流程：创建卡组（或点「示例一键填充」试玩）→ 逐张录入正面/反面，或批量粘贴「正面反面」多行 → 点「全部练习（乱序）」或「今日待复习」开始 → 点击卡片/空格键翻转 → 认识/不认识判定。
调度规则：认识 → 间隔延长（0 天→1 天→ceil(间隔×ease)，ease+0.1）；不认识 → 间隔重置为 1 天（ease-0.2，下限 1.3）；间隔 ≥7 天记为已掌握。
备份：卡组自动存本浏览器；换设备前先「导出当前卡组 JSON」，到新设备上「导入 JSON 文件」恢复。
