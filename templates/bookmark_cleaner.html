使用说明

  1. 在浏览器书签管理器中选择「导出书签」，得到 bookmarks.html（Chrome / Edge / Firefox 均导出 Netscape 标准格式）。
  2. 把文件拖到上方导入区（或点「载入内置示例」直接体验）：页面即时给出总链接/文件夹数、重复 URL 组、重复标题组、域名 Top20、空文件夹。
  3. 重复 URL 组默认保留每组最早收藏的一条，可逐条改选保留项；重复标题组仅提示，需手动勾选；空文件夹默认勾选删除。
  4. 点「应用删除」即时刷新统计；「导出」下载 bookmarks-cleaned.html；「校验导出」会在内存里重新解析一次，确认格式合法再回浏览器导入。
  5. 误删了？点「重置为导入时状态」一键恢复（重置前记得先导出已清理的版本）。

常见问题

URL 归一化去重是什么口径？
host 转小写、去掉默认端口（:80/:443）与末尾斜杠（根路径除外）、去掉 #fragment 后比较；query 参数保留（?x=1 与无参数视为不同页面）。https://Example.com/a/ 与 https://example.com/a 会被判为同一条。
重复标题为什么默认不删除？
同名可能是不同网站的不同页面（如都叫「首页」），误删风险高，所以只提示、由你逐条勾选确认。
导出的文件浏览器能直接导入吗？
能。导出的是标准 NETSCAPE-Bookmark-file-1 格式，保留原有文件夹结构、HREF / ADD_DATE / ICON 属性；「校验导出」按钮会先重新解析一遍确认合法。
能检测死链吗？
不能，首版不做死链检测（见真限制说明）。如需核验请分批手动打开链接。
我的书签会被上传吗？
不会。文件经 FileReader 在浏览器本地读取解析，页面零 fetch / XHR、零 CDN，书签内容不出本机。

真限制说明

只做本地导入→分析／去重／清理→导出：不做跨设备同步，不做 AI 摘要／语义搜索。
首版不做死链检测：纯前端 no-cors 探测拿不到真实 HTTP 状态码，大批量探测易被目标站限流、误报率高；如需核验请分批手动打开链接。
不收集、不上传：书签文件只在浏览器本地解析与处理，页面零 fetch／XHR、零 CDN，不收集、不上传任何内容。
