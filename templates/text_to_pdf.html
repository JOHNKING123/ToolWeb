📄 文本转 PDF

粘贴文本 → 排版预览 → 浏览器打印对话框选「另存为 PDF」：会议纪要、临时文本一键存档分享

⚠ 真限制先说清楚：本工具不是一键直接下载 PDF。出 PDF 依赖浏览器打印对话框——点「打印 / 另存为 PDF」后，在弹出的打印对话框里把目标打印机选为「另存为 PDF」（Chrome/Edge）或 「Microsoft Print to PDF」（Windows），再点保存。纸张尺寸、页眉页脚（网址/日期/页码）也在该对话框里设置。

输入

字符 0 · 行 0 · 词 0

排版选项

打印预览 （所见即打印效果；打印时只输出本文档，工具界面不会被打出来）

在此粘贴文本，排版预览将显示在这里

打印对话框使用说明：目标打印机选「另存为 PDF」→ 按需调纸张尺寸与边距 → 如不想在每页打出网址/日期，把「页眉和页脚」复选框关掉 → 点保存。

使用说明

  1. 在「输入」区粘贴文本（可选填标题，标题会显示在文档页眉）。
  2. 在「排版选项」区调整字号、行距、页边距、纸张方向、字体，预览区实时更新。
  3. 点「打印 / 另存为 PDF」，在浏览器打印对话框中把目标选为「另存为 PDF」，点保存即得 PDF。
  4. 段落按空行分段显示；勾选「段落防断裂」后单个段落不会被分页劈开。
  5. 输入框下方实时显示字符数、行数、词数。

常见问题

为什么不是一键下载 PDF？
本工具走「排版打印视图 → 浏览器打印」路线，零依赖、零 CDN。要生成真正的 PDF 文件，必须经过浏览器打印对话框选「另存为 PDF」这一步——这是浏览器的能力边界，不是本工具的 bug，页面顶部已明示。
和「DOC 转 PDF」有什么区别？
「DOC 转 PDF」是上传 DOC/DOCX 文档、经服务端转换的工具；本工具是纯文本粘贴、纯前端排版、零上传，分工不同：手头是现成文档用前者，是临时文本/会议纪要用本工具。
打印出来的每页都有网址和日期，怎么去掉？
那是浏览器自动加的页眉页脚，在打印对话框里取消勾选「页眉和页脚」即可。本工具的「页眉（标题＋日期）」是文档内容的一部分，不受该开关影响。
我想打横向/调页边距，在哪里调？
纸张方向、页边距、字号、行距、字体都在本页「排版选项」里调，预览实时更新；纸张尺寸（A4/Letter 等）在浏览器打印对话框里选。
我的文本会被上传吗？
不会。排版全部在浏览器本地完成，本页面零网络请求，文本不出本机。

真限制说明

非一键直下：出 PDF 必须经浏览器打印对话框选「另存为 PDF」/「Microsoft Print to PDF」，本工具不直接生成 PDF 文件下载。
纸张尺寸看浏览器：A4/Letter 等纸张尺寸、份数、目标打印机均在打印对话框里设置，本页只管排版（字号/行距/边距/方向/字体）。
浏览器页眉页脚另算：打印对话框「页眉和页脚」开关控制的是浏览器自动加的网址/日期/页码，与本工具的文档页眉（标题＋日期）是两回事。
零上传：本页面零 fetch / XHR、零 CDN，全部排版在浏览器本地完成，不收集、不上传任何内容。
