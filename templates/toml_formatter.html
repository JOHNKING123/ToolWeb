写法说明
key = value裸键、单双引号键、点分隔键
[a.b] / [[a.b]]表与表数组
"..." / '...' / 多行基本、字面、单行与多行字符串，含常用转义

使用说明

1. 粘贴 TOML 到上方输入框（或点「载入示例」）；输入或选项任一变化即实时重算。
2. 校验通过时显示「校验通过，共 N 个键、M 张表」；不通过时逐条中文提示并指明行列，输出区保留上一次有效结果。
3. 点「复制格式化结果」复制输出区内容；「下载 formatted.toml」下载内容与输出区一致；复制失败时页面会提示手动复制指引。
4. 压缩模式会去掉全部注释与空行、数组强制单行，开启时需二次确认；关闭后注释与空行即恢复。

常见问题

为什么提示重复的键？
同一表内同一键出现两次即报错并指明第二处行列；点分隔键的中间段已作表时，再把该段定义为值也会报错。
为什么字符串／数组／表头未闭合会报错？
单行字符串换行前未闭合、数组缺 ]、表头缺 ] 或 ]] 时，均按起始位置中文定位，不输出半截结果。
格式化会改我的键顺序或删注释吗？
不会。本工具不排序、不删键、不丢注释，只规范空白与缩进；只有压缩模式会去掉注释与空行，开启时有二次确认。
我的 TOML 会上传吗？
不会。TOML 全部在浏览器内解析与序列化，本页面零网络请求，数据不出本机。

真限制说明

只做格式化与语法校验、不做语义配置推荐：不提示「该配什么值」、不按应用校验键名语义。
不排序、不删键、不丢注释：格式化只规范空白与缩进，键顺序、表顺序、注释原样保留；压缩模式除外（压缩模式明示会去掉注释与空行）。
格式化失败不覆盖原文：校验不通过时输出区保留上一次有效结果，绝不把半截输出当结果；空输入时提示「请输入 TOML」。
只做常用 TOML 语法子集、不承诺完整 TOML v1.0：超出子集时中文提示并指明行列，不静默丢弃内容。
零上传：本页面零 fetch／XHR、零 CDN，全部解析与序列化在浏览器本地完成，TOML 不出本机。
