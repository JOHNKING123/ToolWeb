help_outline 使用说明

怎么用：把文件拖进上方虚线框（或点「选择文件」），选好算法后点「开始计算」；每个文件独立显示进度条，算完即出哈希值，点「复制」即可粘贴使用。
校验下载文件：把官网公布的 SHA256 值粘贴到对应文件的比对框，点「比对」——一致显示绿色「文件完整」，不一致显示红色警告。比对时自动忽略大小写、空格、换行，也支持直接粘贴 sha256sum 输出的「哈希值＋文件名」整行。
大文件不卡死：文件按 4MB 分片流式读取，哈希在 Web Worker 后台线程里增量计算，内存占用恒定、页面保持流畅；1GB 以上大文件也可以算，只是耗时稍长（纯 JS 计算约数十 MB/秒）。
多文件队列：一次可加入多个文件，按顺序逐个计算；计算过程中可点「取消计算」随时终止当前文件。
算法怎么选：对照官方值用哪个算法就选哪个——绝大多数官网（系统镜像、安装包）公布的是 SHA-256；SHA-512 更长更安全；SHA-1 仅用于核对老旧软件的校验值。
隐私：所有计算都在浏览器本地完成，文件不会上传到任何服务器。

quiz 常见问题

文件会被上传到服务器吗？
不会。分片读取和哈希计算都在浏览器本地的 Web Worker 线程里完成，不发起任何后端请求、不上传任何文件内容，你可以在开发者工具 Network 面板验证，也可以断网使用。
计算结果和 sha256sum 命令行一致吗？
一致。本工具内置的 SHA-256 / SHA-512 / SHA-1 增量实现已用标准测试向量与 sha256sum / sha512sum / sha1sum 命令行交叉验证（10MB 随机文件、4MB 边界文件、空文件三算法全对）。
1GB 以上的大文件会卡死浏览器吗？
不会。文件按 4MB 分片逐块读取，任意时刻内存里只保留当前分片；计算在 Worker 后台线程进行，主线程只更新进度条，页面保持可操作。耗时取决于纯 JS 计算速度（约数十 MB/秒），1GB 文件约需一两分钟。
比对时官方值大小写/换行不一样怎么办？
不用管。比对前会自动归一化：转小写、去掉全部空格/换行/制表符；直接粘贴 sha256sum 的「哈希值＋文件名」整行也能识别。
为什么切换算法后要重新计算？
不同算法的摘要值完全不同、无法互相转换，所以切换算法会自动把已有结果标记为待计算，点「开始计算」重新跑一遍即可。
取消计算后文件还在队列里吗？
在。取消只终止当前文件的计算，该文件回到待计算状态，可随时重新开始；用行右侧的 × 可把单个文件移出队列。
