help_outline 常见问题

块大小和重叠度怎么选？
中文问答场景常见起点：块大小 300–800 字符、重叠 10%–20%。块太大检索时带入无关上下文、浪费 token；块太小语义被切碎。用本工具拖动参数，盯着「平均 token/块」和「最大块 token」调到顺眼再定。
三种策略分别适合什么场景？
固定字符数最简单、块大小均匀，但可能拦腰切断句子（靠重叠度缓解）；按段落语义最完整，但段落长短不一、可能出现超大块；按句子粒度最细，适合做精排前召回的候选池。正式建索引前建议三种都预览一遍。
预估 token 准吗？
是本地估算口径：与本站 AI Token 计数器相同的轻量 BPE 风格分段计数（英文按子词、数字分段，中文逐字），与官方 tokenizer 量级接近、不是逐 token 精确值。看分布、调参数够用；卡硬上限时请留 5%–10% 余量。
为什么按句子切分有时会切错？
分句是启发式的：见到「。！？；…．.?!;」就切。英文缩写（如 v1.2）、小数点、省略号排版都可能误切 —— 这是已知限制，分句结果只用于预览调参，不建议直接作为生产切分依据。
文本会上传到服务器吗？
不会。分块、计数、高亮、导出全在浏览器本地 JavaScript 里完成，脚本中没有任何 fetch / XHR 上传逻辑。可在开发者工具 Network 面板自证，也可断网使用（首次加载页面除外）。
