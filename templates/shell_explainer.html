五条真限制

1. 只解释、不执行：本工具不会运行你的命令，也无法告诉你实际运行结果；执行前请自行在安全的环境核对。
2. 词典有限：只内置 25 个常用命令的常用旗标（每命令 6–15 个），未收录的命令与旗标会明确标注「未收录」，绝不编造含义。
3. 不展开变量与命令替换：$VAR、$(...)、反引号、通配符 * ? 只按字面解释，不做实际展开。
4. 不解析脚本结构：if / for / while、函数定义、here-doc 等只做词法切分，不做语义分析。
5. 危险检测只是启发式提醒：能识别 rm -rf、--no-preserve-root、chmod 777、curl|sh、dd of=/dev/ 等常见危险模式，但不能保证发现所有危险操作。

常见问题

组合短旗标是怎么拆开的？
像 tar -czvf 这样的组合会被自动拆成 -c -z -v -f 逐个解释；带值的旗标（如 -f 后面跟文件名）会把下一个词当作它的值。
「未收录」是什么意思？
词典只覆盖 25 个常用命令的常用旗标。遇到未收录的命令或旗标，本工具会明确列出来、而不是猜一个含义给你；请自行查阅 man 页核实。
危险警示会拦截命令吗？
不会。本工具根本不执行命令，警示只是提醒你复核：例如 rm -rf / 会删整个系统、curl … | sh 会直接执行远程脚本。
我的命令会被上传吗？
不会。解析、释义与危险检测全部在本地完成，不发起后端请求；你可以在 DevTools 的 Network 面板验证（除加载本页面资源外无其他请求）。
