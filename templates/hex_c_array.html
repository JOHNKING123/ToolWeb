使用说明

  1. 在「输入」区顶部切换输入类型：HEX 文本（串口/抓包数据）、字节列表（十进制）、C 数组（已有代码）。
  2. HEX 输入容忍连续 hex（A1B2C3）、空格/逗号/换行分隔、0x 前缀、大小写混写；非法字符会定位到具体位置并报错。
  3. 在「输出格式」区选择目标格式：C 数组（数组名/数据类型/每行字节数/0x 或 h 后缀/大小写可配）、HEX 字符串三种格式、字节列表、Base64。
  4. 点「转换」生成结果，可一键复制或下载（C 数组存为 .h 文件，可直接贴进固件工程）。
  5. 输入框下方的信息栏实时显示字节数、C 数组行数估算与输入字符数。

常见问题

能解析 Modbus 帧并拆解寄存器字段吗？
不能。本工具只做字节↔文本的格式互转，不做任何帧语义解析。需要按 Modbus 协议拆解字段、校验 CRC 请使用 Modbus RTU 帧生成与校验器（帧语义解析 vs C 数组格式互转，分工明确）。
为什么粘贴的 hex 报「非法字符」？
HEX 文本只允许十六进制数字（0-9、a-f、A-F）、0x 前缀、空格、逗号与换行分隔。冒号、分号、引号等都会报错并给出字符位置，请去掉再试。
C 数组解析支持哪些写法？
支持 const uint8_t data[] = { 0xA1, 0xB2, 195 }; 形式：类型可为 uint8_t／unsigned char／char，可省略 const 与数组长度；元素可为 0x 前缀十六进制、十进制混写或 h 后缀十六进制（如 A1h）。
生成的 C 数组怎么用？
点「下载结果」存为 .h 文件，或一键复制后粘贴进固件工程；数组名/数据类型/每行字节数/前缀/大小写均可在输出区上方调整后再生成。
我的输入会被上传吗？
不会。全部转换在浏览器本地完成，本页面零网络请求，输入内容不出本机。
