help_outline 使用说明

转义口径（默认，与 JSON.stringify 一致）：双引号 → \"、反斜杠加倍、换行 → \n、回车 → \r、制表符 → \t、退格 → \b、换页 → \f、其余控制字符 → \u00XX；中文等非 ASCII 与斜杠 / 默认原样保留。
两个开关：仅转义方向生效。开「转义非 ASCII」时 你好 → \u4f60\u597d；开「转义斜杠」时 / → \/；关时原样保留。反转义方向两种写法均可还原，无须开开关。
反转义：只认 JSON 字符串转义序列。非法输入（行尾孤立反斜杠、未转义的裸双引号、非法转义字母、截断的 \uXXXX）会中文报错且结果区为空，不输出半截还原结果。
示例：点「载入示例」得到含中文引号、真实换行、反斜杠路径、制表符的一段文本；切到反转义方向再载入示例，可验证转义结果双向往返后与原文逐字一致。
隐私：全部处理在浏览器本地完成，不发起网络请求，不上传输入内容。

quiz 常见问题

这个工具和 JSON 解析器有什么区别？
对象不同：JSON 解析器格式化与验证整份 JSON 文档；本工具只对一段普通文本做字符串层面的转义／反转义，输入不必是合法 JSON。想格式化整份 JSON 文档去 JSON 解析器。
转义后中文为什么没变成 \uXXXX？
这是默认口径：默认与 JSON.stringify 一致，中文等非 ASCII 原样保留。需要 \uXXXX 形式时打开「转义非 ASCII 为 \uXXXX」开关，你好 就会变成 \u4f60\u597d。
斜杠 / 默认为什么不转义？
同样是 JSON.stringify 默认口径：斜杠合法且无须转义。需要 \/ 形式时打开「转义斜杠为 \/」开关。
反转义报错「裸双引号」是什么意思？
反转义的输入本身就是一段 JSON 字符串的内容：内容里的双引号必须写成 \"。直接粘贴带裸双引号的文本时请先确认方向——要转义普通文本请选「转义」方向。
反转义能处理单引号字符串或 HTML 实体吗？
不能。反转义只认 JSON 字符串转义序列，不认单引号字符串、不做 HTML 实体解码、不做 URL 解码，非法序列会中文报错而不是静默猜测。
这个页面会联网或上传数据吗？
不会。转义、反转义、开关、复制全部在浏览器本地完成，JS 不含 fetch/XHR 调用，你可以在开发者工具 Network 面板验证。
