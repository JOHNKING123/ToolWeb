CSV→Markdown 表格生成器

粘贴 CSV 即生成标准 GFM 表格：每列可选对齐，一键复制或下载 table.md，纯前端不上传

本工具只做表格文本生成：生成结果是 Markdown 文本，不回写 CSV，不转 JSON／Excel；合并／多行单元格只做展平提示，不保留多行结构；分隔符仅支持逗号／分号／制表符三选；日期、金额只按原文本输出，不验合法性、不算合计。

使用说明

  1. 先粘贴 CSV：或点「读取本地 .csv 文件」在本机读文件（FileReader，不上传）；输入为空时不输出表格。
  2. 再选分隔符：逗号默认，分号、制表符三选，切换后实时重生成；其他分隔符（如竖线）本轮不支持。
  3. 表头开关：首行默认作表头；取消勾选后自动生成「列1、列2…」，原首行也计入数据行；表头为空的列用「列 N」占位。
  4. 对齐：每列下拉框单独选左对齐／居中／右对齐，默认左对齐；「全部对齐」三个按钮一键同步所有列。
  5. 转义与展平：单元格里的竖线 | 会转义为 \|，不破坏列结构；单元格内换行展平为空格，并在输出下方提示已展平的处数。
  6. 复制与下载：一键复制把表格文本放进剪贴板；一键下载保存为 table.md；两者内容与输出框一致。
  7. 示例：点「员工表」或「订单表」一键载入，载入后输入、输出、列数统计三者同步，仍可再改再生成。
  8. 互链：要先看表格去 CSV 表格查看器；要转成 JSON 去 CSV⇄JSON 互转；生成的表格要看渲染效果去 Markdown 预览。

常见问题

引号里的逗号、换行会不会把行切错？
不会。引号包字段内的逗号、转义双引号（""）与字段内换行都按 CSV 规则正确解析；引号未闭合时会中文告警并标注「解析告警」，按已读内容尽力生成，不谎称结果完整。
为什么有的行比表头短？
行列数不一致时短行自动补空，不丢行；空尾行不计入行数。
单元格里有竖线怎么办？
竖线会转义为 \|，Markdown 渲染时仍显示为竖线，不会把一列劈成两列。
单元格里的换行去哪了？
展平为空格了：GFM 表格一行就是一行，无法保留多行单元格；输出下方会提示「已把 N 处单元格内换行展平为空格」。
能把生成的表格改回去存成 CSV 吗？
不能。本工具只做表格文本生成，不回写 CSV、不转 JSON／Excel；要改数据请用 Excel 打开原文件修改。
我的 CSV 会被上传吗？
不会。粘贴与本地文件读取均只在浏览器内处理，零网络请求，零 CDN，本页 JS 源码无任何 fetch／XHR 调用。
