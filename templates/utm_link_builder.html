help_outline 使用说明

怎么用：粘贴推广落地页链接 → 点渠道预设或手动填 utm_source / utm_medium / utm_campaign（必填），utm_term / utm_content 选填 → 点「生成 tagged 链接」→ 「一键复制」发到对应渠道。
五个参数各管什么：utm_source 是流量来源（如 wechat / baidu / google），utm_medium 是媒介类型（如 social / cpc / email），utm_campaign 是活动名称（如 summer_sale），utm_term 是广告关键词，utm_content 用于区分同一活动的 A/B 素材。
拼接规则：原有查询串保留、用 & 续接；#hash 保留在末尾，参数插在 # 之前；参数值按百分号编码（空格 → %20，中文 → 百分号编码）；空的选填参数省略；顺序固定为 source → medium → campaign → term → content。
复用旧链接：把别人发来的 tagged 链接粘贴到「粘贴回填解析」，utm 参数会自动回填表单，改个 campaign 就能生成新活动的链接。
「URL 一条龙」：生成推广码？用 二维码工具 把 tagged 链接做成推广码；想把别人分享链接里的追踪参数清掉再转发？用 URL 追踪参数清除器 —— 拼参数推广、清参数净化，拼 ↔ 清双向打通。
