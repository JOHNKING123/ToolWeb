粘贴 Markdown 或导入 .md，实时预览排版，一键导出格式完整的 .docx；纯浏览器本地处理，数据不出浏览器

verified
诚实声明：导出的是标准 .docx（自研 OOXML 拼装，Word/WPS 可直接打开）；样式映射：H1–H6→标题样式、加粗/斜体/删除线/行内代码、列表自动编号、引用块左边框+缩进、表格表头底色+边框、代码块等宽+浅底、超链接蓝色下划线。只有 data:image/…;base64,… 形式的本地图片会被嵌入，网络图片（http 链接）因浏览器跨域与离线限制无法抓取，会以文字占位提示；行内小图导出为独立居中图片段落。请核对右侧预览再导出。

使用说明

怎么用：把 AI 生成的 Markdown 长文（报告/论文/周报/公文）粘贴到左侧，或导入 .md 文件 → 右侧实时预览排版 → 点「导出 .docx」下载 Word 文档（文件名自动带时间戳）。
样式映射：#–######→Word 标题 1–6；**加粗**/*斜体*/~~删除线~~/`代码`；-/1.→项目/编号列表（支持嵌套与续编号，导出后每段列表独立编号）；>→引用块（左边框+缩进+斜体）；```→等宽+浅底代码块；| 表 |→带边框表格（表头底色+加粗，对齐方式保留）；[文字](链接)→蓝色下划线超链接；---→分隔线；- [ ]→☐/☑ 任务列表。
图片：只有 data:image/png;base64,… 这类内嵌 base64 图片会被真正嵌入 .docx（自动按宽高比缩放、最宽 520px）；网络图片会以灰色文字占位提示，不会静默丢失。
导出 .md：把编辑区当前内容存为 .md 文件，方便存档。
隐私：Markdown 解析、预览渲染、docx 拼装（自研 zip 打包）全程在你的浏览器里完成，文本与图片只在浏览器内存里流转，不经过任何服务器、不上传任何内容；页面无任何外部 JS/CSS 依赖（除站内公共样式与图标字体）。
适用边界（如实说明）：数学公式（LaTeX）、脚注、目录 TOC、页眉页脚暂不支持，会按普通文本导出；超大文档（几十万字符）生成可能需要几秒，属正常。
「Markdown 一条龙」：先用 Markdown 预览 快速看排版，用 AI 文本清洁器 清掉 AI 回答里的零宽字符等杂质，回答里的表格用 Markdown 表格转 Excel 转成 .xlsx，需要发公众号再用 Markdown 公众号一键排版 —— 写稿、转表、排版、交 Word，一套流程走完。
