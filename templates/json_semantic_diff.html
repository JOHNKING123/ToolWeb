📖 对比规则说明

对象按键名对齐比较，键顺序无关 —— {"a":1,"b":2} 与 {"b":2,"a":1} 判定为无差异；缩进、换行、多余空白不产生误报。数组按索引逐项比较（不做乱序匹配，接口字段顺序变化本身即是有意义的差异）。
四态分类：新增（右侧多出的键/元素） / 删除（右侧缺失的键/元素） / 修改（同类型值变化） / 类型变化（如 "99.9" 字符串变为 99.9 数字 —— 接口回归中最容易踩坑的一类）。
JSONPath 定位：每条差异标注路径（如 $.data.items[1].price），点击后两侧渲染区自动滚动并高亮闪烁定位。仅看差异可折叠未变化的行，聚焦改动。
互链工具：先用 JSON 解析器 格式化与校验单份 JSON；需要逐行文本对照时用 文本比较；结构级语义对比就用本工具。
隐私：全程无网络请求 —— 解析、对比、渲染都在你的浏览器里完成，可在 DevTools Network 面板验证。
