dashboard 本地看板任务管理

免注册的本地拖拽看板：默认待办 / 进行中 / 已完成三列，列可重命名、增删（上限 8 列）、左右调序；卡片有标题（必填）＋描述＋高 / 中 / 低三色优先级＋截止日期（过期标红）＋多标签。桌面端拖拽跨列移动、列内插入指定位置（插入线指示）；手机/平板用卡片「移到某列」菜单降级操作。优先级 / 标签筛选＋全文搜索、一键清空已完成、JSON 导出 / 导入备份一应俱全。

help_outline 使用说明

桌面端怎么移动卡片？
按住卡片拖到目标列，拖动时会出现蓝色插入线，松手卡片就插入到线的位置（可跨列、可插在列内任意两张卡片之间）。列头「‹ ›」箭头可调整列顺序。
手机/平板上拖不动怎么办？
触屏不支持 HTML5 拖拽，这是浏览器限制。点卡片右下角「移到」按钮，选择目标列与顶部/底部位置即可移动；列顺序用列头箭头调整。
我的数据存在哪里？会同步吗？
只存在本浏览器的 localStorage（键 tw_kanban_board_v1），不会同步到任何服务器或其它设备。换浏览器、换电脑或清除网站数据后看板会丢失——重要内容请定期点「导出」保存 JSON 备份，换设备后用「导入」恢复。
浏览器提示存储损坏 / 看板变空白了怎么办？
如果本地数据损坏（如被其它程序改写），页面不会白屏，会自动重建空白看板并弹出提示。坏数据无法挽回，所以建议定期导出备份。
标签怎么写？
新建/编辑卡片时在「标签」栏用中文逗号或英文逗号分隔多个标签，如 工作，紧急。标签会出现在顶部筛选下拉框里，可按标签过滤。
「清空已完成」会删掉什么？
只清空「已完成」列的全部卡片（列本身保留，其它列不受影响），执行前会二次确认，且不可撤销。如想清空其它列，可删除该列或逐张删除卡片。清空前建议先导出备份。
脚本会联网吗？
不会。页面脚本不发起任何 fetch / XMLHttpRequest 请求，导入导出都是本地文件读写，你可以断网后验证。
