difference v3 / v4 版本差异说明

命名类重命名（切换版本后输出自动调整）：rounded-sm→rounded-xs、rounded→rounded-sm、shadow-sm→shadow-xs、shadow→shadow-sm、blur-sm→blur-xs、flex-shrink-*→shrink-*、flex-grow-*→grow-*、bg-gradient-to-*→bg-linear-to-*、outline-none→outline-hidden。
动态间距（仅 v4）：v4 的间距 scale 是动态的，任意 4px 倍数都合法 —— 如 padding: 18px 在 v4 输出 p-4.5，v3 则只能用任意值 p-[18px]。
important 修饰符：v3 输出前缀式 !p-4 / md:!p-4，v4 输出后缀式 p-4! / md:p-4!。
两版一致：颜色色板、字号、字重、Flex/Grid 布局、定位等命名类在 v3/v4 中相同。

help_outline 常见问题

转换逻辑是精确的吗？颜色是怎么匹配的？
颜色走精确色板匹配：先把你的颜色值归一化为标准 hex（如 #3b82f6、rgb(59,130,246)、#fff 都会归一），再与 Tailwind 默认色板逐项比对，命中才输出 bg-blue-500 这类命名类；色板里没有的颜色输出任意值如 bg-[#12ab34]，视觉 100% 还原。
「任意值」和「需手写」有什么区别？
「任意值」指 Tailwind 原生支持的 [...] 语法（如 w-[137px]、[clip-path:circle(50%)]），可直接用；「需手写」指该声明没有可靠的工具类表达（如 CSS 变量定义 --brand: #fff），输出原声明并附行内注释提示，需你手动处理。
媒体查询怎么转换？
@media (min-width: 768px) 这类条件按断点映射为 sm:（640px）、md:（768px）、lg:（1024px）、xl:（1280px）、2xl:（1536px）前缀变体；max-width 映射为 max-sm: 等；非常规断点输出 min-[500px]: 任意变体。
只粘贴几条裸声明（没有选择器和花括号）可以吗？
可以。解析器做了容错：padding: 16px; color: red 这样的裸声明会被当作一条匿名规则处理，照样逐条输出。
我的 CSS 会上传到服务器吗？
不会。解析、映射、预览、复制、下载全部在浏览器本地 JavaScript 里完成，脚本中没有任何 fetch / XHR 上传逻辑，可断网使用（首次加载页面除外）。
转换结果能直接用在项目里吗？
命名类和任意值类都是标准 Tailwind 语法，可直接粘贴进 class 属性。注意两点：一是确认项目用的是 v3 还是 v4（页内可切换）；二是「需手写」的条目要手动补 CSS。
