CSV 表格查看器

粘贴 CSV 即看表格：表头排序、全局搜索、列筛选、分页渲染，纯前端不上传

本工具只查看、排序、筛选：不编辑单元格，不转换格式，不保存、不导出文件。要改数据请用 Excel；要转成 JSON 请去 CSV⇄JSON 互转。分隔符仅支持逗号／分号／制表符三选；超大文件建议先在本地拆分再查看；日期、金额只按文本或数字排序，不验合法性、不算合计。

使用说明

  1. 先粘贴 CSV：或点「读取本地 .csv 文件」在本机读文件（FileReader，不上传）；输入为空时不输出结果。
  2. 再选分隔符：逗号默认，分号、制表符三选，切换后实时重解析；其他分隔符（如竖线）本轮不支持。
  3. 表头开关：首行默认作表头；取消勾选后自动生成「列1、列2…」，原首行也计入数据行。
  4. 排序：点击表头在升序、降序、取消三态切换；数字列按数值排、文本列按字符串排，空值恒置末尾。
  5. 筛选：全局搜索命中任意列即保留该行；每列列头下的筛选框为文本包含匹配，与全局搜索叠加生效；行数统计与分页同步变化。
  6. 分页：每页 50／100／200 行可选，上一页、下一页、页码跳转均可用；大数据量下只渲染当前页。
  7. 示例：点「员工表」或「订单表」一键载入，载入后输入、表格、行数统计三者同步，仍可再改再看。
  8. 互链：要转成 JSON 去 CSV⇄JSON 互转；本工具不做格式转换，不生成 Markdown 表格。

常见问题

引号里的逗号、换行会不会把行切错？
不会。引号包字段内的逗号、转义双引号（""）与字段内换行都按 CSV 规则正确解析；引号未闭合时会中文告警并按已读内容尽力渲染，不谎称结果完整。
为什么有的行比表头短？
行列数不一致时短行自动补空，不丢行；空尾行不计入行数。
排序时空值为什么总在最后？
这是有意为之：空值恒置末尾，与升序、降序无关，避免缺失值混进数值或文本顺序里误导判断。
能直接改表格里的数据吗？
不能。本工具只查看、排序、筛选，不编辑、不保存、不导出；要改数据请用 Excel 打开原文件修改。
文件很大打开会卡吗？
分页只渲染当前页，但解析仍在浏览器内一次完成；行数极大时仍可能卡顿，超大文件建议先在本地拆分再查看。
我的 CSV 会被上传吗？
不会。粘贴与本地文件读取均只在浏览器内处理，零网络请求，零 CDN，本页 JS 源码无任何 fetch／XHR 调用。
