适用边界：本工具生成的是格式合法的假数据，不能通过运营商/银行/公安的真实性核验，仅用于开发联调与界面测试。

quiz 常见问题

生成的数据会上传到服务器吗？
不会。所有生成逻辑都在浏览器本地的 JavaScript 里运行，不发起任何后端请求，你可以在开发者工具 Network 面板验证，也可以断网使用。
身份证、银行卡号码是真的吗？
是虚拟号码：校验位按真实算法生成（身份证第 18 位、银行卡 Luhn 位都合法），但号码本身随机编造，不能用于任何真实业务、实名认证或支付场景，仅供格式测试。
seed 是什么？为什么两次生成结果一样？
seed 是随机数种子。本工具使用 mulberry32 确定性随机算法：相同 seed 加上相同的字段勾选、行数、日期范围，生成的每一行都完全一致，方便测试复现。换 seed 即换一批数据。
一万行会卡吗？
不会。生成 10000 行在普通电脑上只需几十毫秒；预览采用分页渲染（每页 100 行），DOM 只保留当前页；导出直接拼接字符串后下载。
CSV 用 Excel 打开中文乱码怎么办？
导出的 CSV 自带 UTF-8 BOM，Excel / WPS 双击打开即正常显示中文。
SQL 导出支持哪些数据库？
支持 MySQL 与 PostgreSQL 两种方言：标识符引用（反引号 / 双引号）与文件头注释自动切换，多值 INSERT 每 1000 行一条，兼容大多数数据库的导入限制。
