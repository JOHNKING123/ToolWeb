info
真限制说明：
  1. 本工具只是模板拼装，不做 AI 优化：它把你填写的内容原样拼成 XML 结构，不会对提示词的措辞、质量做任何智能改写或优化，写得好不好取决于你填的内容。
  2. XML 标记的遵循程度因模型而异：不同大模型对 <role>、<task> 这类结构化标记的理解和遵循程度不同，建议换 2–3 个模型实测对比后再定稿。
  3. 全部本地生成：拼装、复制、下载都在浏览器本地完成，不联网、不上传任何内容。

help_outline 使用说明

三步使用：① 按七节表单填写（不会写的节直接留空，会被自动省略）；② 点一键预设可快速套用「代码评审 / 英文翻译 / 小红书文案」模板再改；③ 点「一键复制」粘贴给 AI，或「下载 .xml」存档复用。
怎么写出好提示词：角色越具体越好（别只写「你是专家」，写清领域和年限）；任务用动词开头、一次只交代一件事；约束写「不要什么」比写「要什么」更有效；给 1–2 条示例（Few-Shot）往往比长篇描述更管用。
XML 结构说明：输出为 <system-prompt> 根节点，内含 <role>、<task>、<context>、<constraints>、<output-format>、<examples>、<input>；& < > 等特殊字符已自动转义为 XML 实体。
隐私：全部拼装在浏览器本地完成，不发起网络请求，不上传任何内容。

quiz 常见问题

生成的 XML 直接粘贴给 AI 就能用吗？
能。主流大模型（GPT / Claude / Gemini / 国产模型）都能理解这种结构化标记；但各模型对标记的遵循程度不同（见真限制第 2 条），建议先小规模实测。
留空的节会输出空标签吗？
不会。留空（或只填空白字符）的节会被自动省略，约束和示例里填了空白的行也会被过滤掉。
和「AI 提示词脱敏器」是什么关系？
本工具负责把提示词搭成结构；搭好之后如果提示词里含 API Key、数据库连接串等敏感信息，先去「AI 提示词脱敏器」脱敏，再发问更安全。
这个页面会联网或上传数据吗？
不会。表单拼装、复制、下载全部在浏览器本地完成，JS 不含网络请求调用，你可以在开发者工具 Network 面板验证。
