真限制（请先看清再用）：

1. 只转语义结构不转样式：class、内联样式、字体颜色字号没有 Markdown 等价物，一律丢弃（样式不单独列入丢弃清单）。

2. 不抓取网页、只转粘贴的 HTML：本工具不输入网址、不发请求拉取网页，网页内容请先复制 HTML 源码再粘贴。

3. 图片只引用不下载：图片转成 ![alt](src) 原样引用地址，不下载、不转 base64，外链图片会随源站失效而失效。

4. 表格只转 pipe table：合并单元格（colspan / rowspan）没有 GFM 等价物，按拆格展开并在提示区说明，不静默合并。

5. 脚本与样式不执行：script / style 内容不执行、不进正文，只进丢弃清单计数。

menu_book 使用说明

  1. 把 HTML 片段粘贴到输入框，点「转换为 Markdown」：标题、粗斜体、删除线、链接、图片、嵌套列表、引用、代码、表格按 GFM 映射输出。
  2. 嵌套列表每级缩进 2 个空格；有序列表序号按同级顺序递增；换行 br 转成行尾两个空格的硬换行。
  3. 表格转成 pipe table：表头行 + 分隔行，对齐按 th / td 的 align 属性或 style text-align 取左 / 中 / 右，单元格里的 | 转义为 \|，<br> 转为空格。
  4. 围栏代码的语言取 code 的 class（如 language-js 的后缀），没有则不写语言；行内代码用反引号包裹。
  5. 看「已丢弃」清单核对：script / style / 表单控件等无等价物标签按标签名计数列出，脚本样式文本不会混进正文。
  6. 表格含合并单元格时，提示区会说明已按拆格展开：合并格内容保留在左上角，展开的空格留空。
  7. 点「复制 Markdown」或「下载 converted.md」导出；点示例一键载入 4 组典型片段（请按需改写），载入后仍可编辑再转换；点「重置回初始输入」回到本次转换的原始输入。

quiz 常见问题

为什么样式转过去不见了？
因为 Markdown 只有语义没有样式：颜色、字号、class 都没有对应的 Markdown 写法，只能丢弃；需要样式请用转 Word 或公众号排版工具再排。
能直接输入网址抓取网页转换吗？
不能。本工具不抓取网页（会碰到跨域与混合内容限制），请先在浏览器里复制网页的 HTML 源码，再粘贴进来转换。
图片会被下载下来吗？
不会。图片只转成 ![alt](src) 引用原地址，不下载、不转 base64；原图下线后 Markdown 里的图也会失效。
合并单元格怎么处理？
按拆格展开：合并格的内容保留在左上角那一格，rowspan / colspan 展开出来的空格留空，并在提示区说明展开了几处，不会静默把两格拼成一格。
script 里写的内容会跑出来吗？
不会。DOMParser 解析出的脚本不执行，转换时脚本与样式整棵跳过，只在丢弃清单里计数，文本不会混进正文。
我的 HTML 会被上传吗？
不会。全部转换在浏览器本地完成，零网络请求，输入只留在当前页面。
