自由画布收集设计灵感：图片、便签、链接、色板任意排布，模板一键套用，PNG 导出，本地保存零上传

真限制说明：
  1. localStorage 约 5MB 上限：图片以 dataURL 存在浏览器本地存储，图片过多/过大时自动保存会失败并明确提示，请及时导出 JSON 备份；
  2. PNG 只导出画布内卡片：超出 800×600 画布边界的部分不导出，导出前请确认卡片都在画布内；
  3. 链接卡片不抓取内容：只保存标题与 URL，不抓取网页内容/缩略图，零外部请求；
  4. 换浏览器/清缓存看板丢失：看板只保存在当前浏览器本地，换浏览器或清除缓存后丢失，务必导出 JSON 备份。
