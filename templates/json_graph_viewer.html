五条真限制

1. 只做结构图可视化：本工具只把合法 JSON 画成节点连线结构图，不做 JSON 格式化／校验、不做 JSONPath 查询；要排版美化与校验请用 JSON 解析器，要按表达式查节点请用 JSONPath 测试器。
2. 超大 JSON 会截断：输入上限 100000 字符；节点总数超过 3000 时只渲染前若干层并在统计面板明确提示截断层数与个数，不静默丢节点。
3. 循环引用不支持：JSON.parse 本身无法产生循环引用；若以编程方式传入含循环引用的对象，建图会直接报错，不画半张图。
4. 分层树形布局，非力导向图：节点按深度分列、父节点 y 取子节点 y 均值、连线为贝塞尔曲线，不做物理模拟与力导向排布；节点很多时图会很宽很高，请配合折叠与缩放使用。
5. 本地零上传：粘贴的 JSON 只在当前浏览器本地解析、布局与渲染，不上传服务器、不调用任何外部接口；页面不引入 d3 等第三方库、不走 CDN。

常见问题

粘贴的 JSON 报错了怎么办？
页面只显示解析错误信息，不渲染半张图；先用 JSON 解析器定位语法错误（缺逗号、多余尾逗号、单引号等最常见），修正后再生成结构图。
节点太多看不清怎么办？
点节点右上角的 ＋／－ 折叠不需要的分支；滚轮或右上角按钮缩放（0.2–3x）；在搜索框输入 key 或值可高亮并定位到命中节点。
怎么复制某个节点的路径？
点击该节点，下方「选中节点」面板会显示它的 JSON Path（如 $.store.book[0].title），点「复制 JSON Path」即可；含连字符等特殊字符的键会用 $['my-key'] 形式。
我的 JSON 会被上传吗？
不会。解析、布局、渲染与导出全部在本地完成，不发起后端请求；本工具不引入任何第三方库与 CDN，你可以在 DevTools 的 Network 面板验证（除加载本页面资源外无其他请求）。
