真限制（先说清楚）

  • ① 只存本浏览器：笔记存在 localStorage 里，跨设备不同步；清除浏览器数据/换浏览器/重装系统都会丢失——重要笔记请定期导出 JSON 备份，文件形如 studynotes_20261103_030000.json。
  • ② Markdown 为精简子集：只渲染 # ## ### 标题、**加粗**、*斜体*、行内代码与 ``` 代码块、- 无序列表、1. 有序列表、> 引用和 [文字](链接)——表格、任务列表、数学公式等不支持，按原文显示。
  • ③ 纯本地处理：笔记内容只在你的浏览器内流转，不会上传到任何服务器（可在浏览器 Network 面板自证）。

使用说明

流程：点「新建笔记」录入标题＋正文（可选「预览」查看渲染效果）＋打标签 → 笔记自动存本浏览器 → 顶部搜索框全文检索（标题/正文/标签，不区分大小写）→ 点标签胶囊按标签过滤 → 重要笔记点「置顶」置顶。
标签管理：点「标签管理」可重命名标签（同步更新所有笔记）或删除标签（笔记保留）。
备份：「导出 JSON（备份迁移）」导出全部笔记；「导入 JSON 文件」可把备份恢复到本浏览器（原有笔记不受影响，导入条目追加）；每条笔记还可单独「导出MD」为 Markdown 文件。
