使用说明

1. 在「录制选项」按需勾选麦克风 / 系统音频，选择视频比特率三档（默认中档）。
2. 点「🎥 开始录制」，在浏览器原生弹窗里选择要共享的屏幕 / 窗口 / 标签页（要录网页声音请共享「标签页」并勾选「共享音频」）。
3. 录制中可「⏸ 暂停 / ▶ 继续」；点「⏹ 结束录制」或在浏览器共享条点「停止共享」都会结束并生成文件。
4. 结束后页面内回放，一键下载 screen-record-YYYYMMDD-HHmmss.webm（Safari 为 .mp4），可「🔄 重新录制」。
5. 录完想发群 / 做表情包？用 GIF 压缩优化器把录屏压成小体积 GIF（录屏上下游双向联动）；想从录屏里抠关键帧，用 视频帧提取器。

常见问题

录屏文件保存在哪里？只在浏览器内存里生成，点「下载」才会落盘到你的电脑；本页面不上传、不留存，关闭页面即消失。
为什么录出来没有声音？系统音频受限（见下方真限制③）；麦克风需要单独勾选并授权；拒绝麦克风授权只影响声音、不影响画面。
Safari 能用吗？能，输出一般为 mp4；暂停/继续等 API 的支持情况以页面上方「能力检测」为准。
录制时长有限制吗？无硬性限制，但录制内容驻留内存，长时间录制文件会很大，请及时下载；建议单段控制在 10 分钟内。
需要联网吗？录制本身零网络；本页面也不发起任何外部请求（打开页面本身需要联网加载页面）。

真限制说明

  • 必须经浏览器弹窗授权屏幕共享：点击「开始录制」后浏览器会弹出原生选屏窗口（屏幕 / 窗口 / 标签页三选一由浏览器提供）；若拒绝授权或直接关闭弹窗，将无法录制，需重新点击并允许。
  • 输出容器/编码取决于浏览器：页面上方「能力检测」会明示本次实际采用的格式（Chrome / Edge 多为 video/webm;codecs=vp9，Safari 为 video/mp4）；不同浏览器产出的文件后缀与播放兼容性不同，下载文件名会随实际格式自动切换 .webm / .mp4。
  • 系统音频录制受限：系统音频通常仅在共享「标签页」并在浏览器弹窗中勾选「共享音频」时可用；macOS 及部分浏览器、共享整个屏幕/窗口时系统音频不可用，届时只能录到麦克风声音或静音画面，属平台限制非本工具缺陷。
  • 零上传但请注意隐私：录制全程在浏览器本地完成、不上传任何内容；但录屏会如实记录屏幕上的一切——共享屏幕前请关闭微信、邮件、密码管理器等含隐私内容的窗口。
