    使用说明

    1. 每行写一个选择器，也可以在一行里用逗号写多个；空行自动跳过，输入后结果表、排序榜与文本报告实时同步。
    2. 权重读法：(a, b, c) 中 a 是 ID 数，b 是类＋属性＋伪类数，c 是类型＋伪元素数；比较时先比 a，再比 b，最后比 c，通用选择器 * 计 0。
    3. 点「载入示例」可一键看到 #header nav ul li a（1, 0, 4）与 ul#nav li.active a:hover（1, 2, 3）的对决：同为 1 个 ID 时由 b 决定胜负，无需上传即可演示输入→计算→排序→导出全流程。
    4. 非法行只会在结果表中红字标出该行错误，不阻塞其它行的计算；复制与下载只导出合法行的结果。
    5. 要写渐变声明去渐变生成器；要给盒子加阴影或描圆角去阴影与圆角生成器；要调图片滤镜去滤镜生成器——那边产样式声明，本页只算选择器权重。

    常见问题

    :not()、:is()、:has() 怎么算？
    取参数中字典序最大的那个三元组，不是把所有参数加起来；例如 div:not(.foo) 是 (0, 1, 1)，:has(> .active) 是 (0, 1, 0)。
    :where() 为什么总是 0？
    :where() 本身及其参数一律计 (0, 0, 0)，这是规范口径：例如 :where(#a, .b) 仍是 (0, 0, 0)。
    :nth-child(2n of .item) 怎么算？
    伪类本身计 b＋1，再分量加上 of 列表中最大的三元组：li:nth-child(2n of .item) 是 (0, 2, 1)。
    单冒号 :before 算伪类还是伪元素？
    legacy 写法 :before、:after、:first-line、:first-letter 计 c（与双冒号写法一致），其余单冒号计 b。
    我的输入会被上传吗？
    不会。全部解析与比较只在浏览器本地完成，本页面零网络请求，零上传。
