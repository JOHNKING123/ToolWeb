help_outline 常见问题

脱敏后的文本发给 LLM 安全吗？
敏感值已被替换为 __API_KEY_1__ 这类无意义占位符，真实密钥只存在于你本标签页的内存映射表里。只要不同时把映射表发出去，LLM 侧看不到任何真实密钥。
映射表存在哪里？关掉页面会怎样？
只存在本标签页的 sessionStorage（内存级存储）。关闭标签页自动销毁；刷新页面后不恢复，需要重新粘贴脱敏。也可以点「手动销毁映射表」立即清零。
LLM 答案里的占位符怎么还原？
把答案粘贴到第 4 步点「一键还原」，占位符按映射表替换回原始值。注意：必须在同一个标签页里操作 —— 换了标签页或刷新后映射表已销毁，就无法还原了。
识别不到我的密钥格式怎么办？
通用密钥对规则会兜底：key 名含 api_key / secret / token / password 且值 ≥12 字符的 key=value / key: value 都会被识别。若仍漏报，可以先用「文本隐私脱敏工具」做二次检查。
文本会上传到服务器吗？
不会。本工具纯前端运行：文件用 FileReader 本地读取，识别/替换/还原全在浏览器本地 JavaScript 里完成，脚本中没有任何 fetch / XHR 上传逻辑。可打开开发者工具 Network 面板验证无外发，也可断网使用（首次加载页面除外）。
和「文本隐私脱敏工具」有什么区别？
「文本隐私脱敏」面向个人 PII（手机号/身份证号/银行卡号/邮箱/车牌），单程不可逆遮盖；本工具面向开发者密钥（API Key/JWT/PEM 私钥/Token/数据库连接串），特点是可逆：占位符映射表让你能把 LLM 答案一键还原。两者互补。
