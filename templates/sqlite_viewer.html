使用说明

  1. 把 .db／.sqlite 文件拖到上方虚线框（或点「选择文件」）；文件只在浏览器本地读取，不上传。
  2. 首次打开会加载 SQLite 引擎（sql.js WASM 约 700KB，同域自托管，仅加载一次，有进度条）。
  3. 左侧点表名：右侧看表结构（列名／类型／主键）＋数据分页预览。
  4. 在 SQL 编辑器里写 SELECT 查询（支持 WITH／PRAGMA／EXPLAIN），Ctrl+Enter 执行；写入语句会被拦截。
  5. 表预览或查询结果都可一键「导出结果为 CSV」（UTF-8 BOM，Excel 直接打开中文不乱码）。

真限制说明

WASM 约 700KB、首屏延迟加载：SQLite 引擎（sql.js WASM）自托管于本站同域（/tools/static/js/vendor/sqljs/sql-wasm.js＋sql-wasm.wasm，无 CDN），首屏不加载；仅在你第一次选择 .db 文件后才加载，加载中有进度条提示。
只读模式、不支持写入：仅允许 SELECT／WITH／PRAGMA／EXPLAIN，多语句与 INSERT／UPDATE／DELETE／DROP 等一律拦截并提示；如需写回 .db 请用 DB Browser for SQLite 等桌面工具。
大文件（>256MB）拒绝打开：WASM 内存上限使然；表数据走 LIMIT／OFFSET 分页预览（每页 50／100／200 行可选），不会一次渲染上万行卡死页面。
仅支持标准 SQLite 数据库文件格式：加密（如 SQLCipher）或已损坏的文件会直接报错，无法打开。
全程浏览器本地，零上传：本页面不发起任何外部请求（WASM 与脚本均为同域自托管），.db 文件数据不出本机。

常见问题

我的 .db 文件会被上传到服务器吗？
不会。文件经浏览器 File API 在本地读取，SQLite 引擎（sql.js WASM）运行在浏览器内存里；本页面无外部请求、无 CDN，.db 数据不出本机。
为什么第一次打开文件要等一会儿？
首次需要加载约 700KB 的 sql.js WASM 引擎（本站同域自托管），之后再次打开文件无需等待；页面首屏不预载它，所以打开本页本身是秒开的。
能用这个工具修改 .db 文件吗？
不能。本工具是只读查看器，INSERT／UPDATE／DELETE 等写入语句会被拦截；数据库文件本身也从未被改动。如需修改请用 DB Browser for SQLite。
支持多大的数据库文件？
上限 256MB；表数据分页预览，不会一次渲染全部行。超过上限的文件会被拒绝打开（浏览器 WASM 内存限制）。
加密的数据库能打开吗？
不能。仅支持标准 SQLite 文件格式，SQLCipher 等加密文件或已损坏的文件会直接报错。
