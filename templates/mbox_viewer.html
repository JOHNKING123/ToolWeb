help_outline 使用说明

支持哪些文件？
标准 mbox 格式（每封邮件以 From 行分隔）：Thunderbird 本地文件夹导出的无扩展名/mbox 文件、Gmail Takeout 导出的 .mbox。文件按 UTF-8 读取；正文按邮件头声明的 charset 解码（UTF-8 / GBK / ISO-8859-1 等，TextDecoder 支持）。
邮件列表与排序
解析后显示发件人、主题、日期；可按日期倒序/正序、发件人、主题排序。📎 角标表示该邮件含附件。
正文怎么显示？
multipart/alternative 优先取纯文本版；只有 HTML 版时转为纯文本安全显示（不执行任何脚本与外部资源）。正文统一做 HTML 转义后渲染。
全文搜索搜什么？
主题、发件人、收件人、正文、附件文件名，不区分大小写，输入即过滤。
附件下载
附件清单按全部邮件聚合：单个下载，或点「全部下载」逐个触发（浏览器可能逐个弹出确认）。文件名按 Content-Disposition filename / Content-Type name 提取并做 encoded-word 解码。
损坏邮件块
缺失邮件头、空块等损坏块会被跳过并计数提示（如“跳过损坏块 1 个（缺失邮件头×1）”），不中断其余邮件解析。
隐私与大文件
纯前端、零后端、零上传：脚本内无 fetch / XMLHttpRequest，可在 Network 面板验证。超过 200MB 的文件会先弹确认框提示内存风险；解析是大文件建议关闭其他标签页。
已知限制
8bit 原始非 UTF-8 正文（如直接 GBK 明文）依赖浏览器按 UTF-8 读取，可能显示异常——实务中 Thunderbird / Gmail 导出的非 ASCII 正文均为 quoted-printable / base64，不受影响；PGP/MIME 加密邮件只显示密文，不做解密。
