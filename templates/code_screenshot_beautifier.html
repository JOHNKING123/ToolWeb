help_outline 使用说明

  1. 在输入区粘贴代码（语言默认自动检测，也可手动指定）。
  2. 在样式区挑选主题（One Dark / Dracula / GitHub Light / Solarized Light）、背景（渐变 / 纯色 / 透明）、字号、行号与窗口标题。
  3. 预览区实时渲染 macOS 风窗口截图：红绿灯按钮、圆角阴影、语法高亮。
  4. 点「下载 PNG」保存图片，或点「复制 PNG」直接粘贴到文档/聊天中。

quiz 常见问题

代码会上传到服务器吗？
不会。语法高亮与图片渲染全部在浏览器本地完成，本页面不发起任何网络请求，可用 DevTools 的 Network 面板验证。
支持哪些语言的高亮？
JavaScript、TypeScript、Python、Go、Java、HTML、CSS、JSON、SQL、Shell、Markdown 共 11 种，另有自动检测。关键字、字符串、注释、数字分别着色。
导出的 PNG 清晰度如何？
以 2 倍像素密度渲染，文字边缘清晰，适合直接用于文章、PPT 与社交媒体分享。
代码很长怎么办？
超过 300 行或 5 万字符时会自动截断仅渲染前 300 行并给出提示，建议分段截图以保证清晰度与性能。
「复制 PNG」按钮没反应？
复制图片到剪贴板需要浏览器支持 ClipboardItem 图片写入（Chrome / Edge 可用）；Safari / Firefox 等不支持时会给出明确提示，请改用「下载 PNG」。
