    help_outline 使用说明

    两种模式有什么区别？
    「按住说话 / 松开结束」：按住麦克风按钮开始识别，松开立即结束，适合逐句听写；「点击切换」：点一下开始、再点一下停止，适合长段连续说话（识别器在语音停顿后可能自动断开，本工具会自动续听）。模式偏好会自动记住。
    为什么提示「没有检测到语音」？
    浏览器在一段时间内没收到有效语音会报 no-speech。请靠近麦克风、提高音量再说一遍；环境太安静或麦克风被独占也可能触发。
    麦克风权限被拒绝了怎么办？
    点击浏览器地址栏左侧的锁形 / 摄像头图标，把「麦克风」设为「允许」，然后刷新页面重试。首次使用时浏览器会弹窗请求权限，请务必点「允许」。
    哪些浏览器能用？
    需要支持 Web Speech API 的浏览器：桌面版 Chrome、Edge。Firefox 与 iOS Safari 目前不支持，会显示明确提示。移动端 Chrome 部分可用，但体验不如桌面版。
    我的语音会被上传吗？
    会——这是必须如实说明的：Chrome/Edge 的语音识别是云端转写，麦克风音频会发送到云端服务（Google）进行识别，并非离线。页面自身脚本零网络请求，但识别通道由浏览器控制。敏感内容请斟酌。
    历史存在哪里？会丢吗？
    只存在本机浏览器 localStorage（rd:history，最多 200 条），刷新不丢；清除浏览器数据会一并清除。单条可复制/删除，可一键复制全文、二次确认后清空。
    识别准确率不高怎么办？
    确认识别语言选对了（普通话/粤语/英语/日语），靠近麦克风、语速放慢、减少背景噪音。云端转写对标准发音效果最好，方言请选对应语言。
