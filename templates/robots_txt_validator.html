robots.txt 校验与测试器

粘贴已有 robots.txt：分组解析（User-agent 组＋规则行＋行号，Sitemap 单列）、逐行中文化语法校验、URL 允许/禁止测试、六 AI 爬虫放行矩阵。写对没有，贴进来一测便知。

隐私声明：内容不出浏览器。粘贴的 robots.txt 只在当前浏览器本地解析与判定，不上传到任何服务器，不做任何存储与记录。本页面无后端调用、无外部请求，粘贴模式为主、不在线拉取（在线拉取会被 CORS 拦截，索性不做）。

粘贴 robots.txt

输入变化即实时重解析，无需点按钮。从 robots.txt 生成器复制来的文本可直接粘贴到这里校验。注释行（#）与空行保留定位、不计入规则、不报错。

导出为原文原样：本工具只校验与测试，不自动改写规则；复制失败时有降级提示（手动全选复制）。重置后回到默认空状态。

分组解析

语法校验（逐行中文化）

错误级：规则行出现在任何 User-agent 组之前、User-agent 为空、Allow / Disallow 路径缺前导 /、Sitemap 非绝对 URL。警告级：空 Disallow、未知指令、Crawl-delay、同一组内重复规则、指令名大小写混写。

URL 允许 / 禁止测试

判定口径（Google 规范）：同组内最长匹配规则获胜；Allow 与 Disallow 长度相等时 Allow 优先；无匹配规则时默认允许；有专属组时用专属组，否则回落到 * 组；既无专属组又无 * 组时无匹配组、默认允许。

AI 爬虫放行矩阵

判定口径与 URL 测试一致：有该爬虫专属组时用专属组，否则用 * 组；专属组优先于 * 组。

使用说明

1. 把线上或本地的 robots.txt 全文粘贴到上方输入框，分组解析与校验即时出现。
2. 先看校验区：错误必须修，警告逐条确认语义（空 Disallow 不是禁止、Crawl-delay 不被 Google 采纳）。
3. 在 URL 测试区输入要验证的路径与爬虫名，看命中规则与判定依据，确认关键路径没有被误挡。
4. 在 AI 矩阵里确认六个 AI 爬虫对首页的放行状态；具体路径再用 URL 测试逐个核对。
5. 确认无误后复制或下载，覆盖到网站根目录的 robots.txt；写新文件请先去 robots.txt 生成器拼装，再贴回这里校验。

常见问题

Disallow: / 是什么意思？禁止该组爬虫抓取全站；想允许全部应写空 Disallow（Disallow: 后面什么都不写），两者正好相反，别写反。
为什么 Allow 和 Disallow 冲突时 Allow 赢？按 Google 规范，等长冲突时 Allow 优先；不等长时最长的那条赢，与书写顺序无关。
写了规则，AI 爬虫就一定不来吗？不一定。robots.txt 只是君子协定，是否遵守取决于各厂商声明；恶意爬虫根本不会看它。
Sitemap 行写在哪里？与组无关，文件任何位置都可写，但必须是完整 URL；本工具把它单列展示。
路径区分大小写吗？区分。/Admin/ 与 /admin/ 是两条不同路径；指令名（User-agent、Allow 等）不区分大小写。

真限制说明

  • 君子协定，不等于访问控制：robots.txt 只是爬虫君子协定、不等于访问控制，恶意爬虫与攻击者不会遵守；真正敏感的路径请用密码保护或 IP 白名单。
  • Google 规范近似实现：解析与判定按 Google 规范近似实现，不承诺与每个爬虫逐字一致，个别爬虫的扩展指令可能有差异。
  • 粘贴模式为主，不在线拉取：本工具粘贴模式为主、不在线拉取，浏览器跨域限制会拦截对别人网站 robots.txt 的直接读取。
  • 内容不出浏览器：全部解析与判定在本地完成，零 fetch/XHR、零 CDN，文件内容不出浏览器。
  • Crawl-delay 效力因爬虫而异：Crawl-delay 是非标准指令，Google 已忽略，Crawl-delay 效力因爬虫而异，仅作礼貌声明。
