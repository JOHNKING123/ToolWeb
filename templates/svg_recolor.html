SVG 换色器

粘贴或上传 SVG，自动提取颜色成色板；逐色替换或全局色调偏移，消毒后并排预览，复制代码或下载 recolored.svg。

真限制，先说清楚：① 只改行内属性与内联 style 的颜色——外部 CSS（<style> 块与外链样式表）与 currentColor 继承色不在范围，提取报告会给出跳过数；② 渐变引用本身不动、只改色标：fill="url(#渐变)" 不改色，但渐变定义内行内的 stop-color 照常提取替换；③ 命名色只认 16 个 CSS 基础色＋transparent，其余命名色（如 rebeccapurple）不解析、不替换，计入跳过数；④ 预览与导出均先消毒：剥离 <script>、on* 事件属性，javascript: 链接改写为 #，导出结构与原稿一致、仅颜色与危险节点有变；⑤ 不收集、不上传任何内容：粘贴与上传的 SVG 只在浏览器本地解析，本页面不发起任何网络请求。

使用说明

提取：粘贴代码点「提取颜色」，或上传 .svg 文件（≤2MB）自动回填并提取；色板按出现次数降序，并列按首次出现顺序。
逐色替换：在色板行里挑新颜色（取色器或 HEX 输入），点「替换此色」即对该色全部出现处替换；id、文本内容、注释、<style> 块、url(#…) 引用中的同形字符串原样保留。
色调偏移：滑杆选 -180–180°，点「应用色调偏移」对当前全部颜色一次性偏移；红 +120° 变绿，灰色不变，±180° 往返回到原色。
导出：复制换色后代码或下载 recolored.svg；预览与导出均先消毒再替换，顺序固定为消毒→替换。
隐私：所有解析、替换、偏移、导出都在浏览器本地完成，不收集、不上传任何内容。

常见问题

为什么有些颜色没出现在色板里？
本工具只改行内属性与内联 style 的颜色。写在 <style> 块或外链样式表里的颜色、currentColor 继承色、fill="url(#渐变)" 引用本身都不在范围，会计入提取报告的跳过数；渐变定义内行内的 stop-color 则照常提取。
命名色都支持吗？
只认 16 个 CSS 基础色（black／silver／gray／white／maroon／red／purple／fuchsia／green／lime／olive／yellow／navy／blue／teal／aqua，不区分大小写）与 transparent；其余命名色（如 rebeccapurple、grey）不解析、不替换，计入跳过数。
替换会不会改坏 id 或文字？
不会。替换只发生在行内颜色属性值与内联 style 声明内；id、文本内容、注释、<style> 块、url(#…) 引用中的同形字符串原样保留。
导出的 SVG 安全吗？
预览与导出均先消毒：剥离 <script> 块、on* 事件属性，javascript: 链接改写为 #；导出结构与原稿一致、仅颜色与危险节点有变。
SVG 会上传到服务器吗？
不会。粘贴与上传的 SVG 只在浏览器本地解析，上传走 FileReader 本地读取，不经过任何服务器，本页面无后端调用、无外部请求。
