help_outline 使用说明

怎么用：在上方按「编程语言 → 框架/平台 → 系统/IDE」勾选你的技术栈（如 Node + Vue + macOS + VSCode），合并结果实时出现在预览区；点「复制 .gitignore」粘贴到项目根目录，或点「下载 .gitignore」直接保存文件。
拼接顺序：语言模板在前、框架居中、系统/IDE 殿后；每个模板块以 # ===== 模板名 ===== 注释分隔并标注来源，方便日后手动维护。
去重规则：不同模板里的完全相同的行（如 .env、*.log、*.iml）只保留第一次出现的位置，统计栏会显示去掉了多少重复行。
选择记忆：你的勾选会自动存到浏览器 localStorage，下次打开直接沿用上次的组合。
模板来源：内置 github/gitignore 官方模板的主流核心规则（离线可用，不实时拉取）；若项目有特殊忽略需求，下载后可直接在文件末尾追加。
适用边界：本工具只负责生成忽略规则文本，不会替你执行 git add；已经被 git 跟踪的文件即使写进 .gitignore 也不会被忽略，需要先 git rm --cached。

quiz 常见问题

生成的 .gitignore 会上传到服务器吗？
不会。模板库和拼接引擎都在浏览器本地的 JavaScript 里运行，不发起任何后端请求、不上传任何内容，你可以在开发者工具 Network 面板验证，也可以断网使用。
为什么有些模板很长、有些很短？
模板取自 github/gitignore 官方仓库的主流核心规则：语言模板（如 Python、Node）覆盖构建产物/依赖/缓存等通用规则；框架模板只补该框架特有的目录（如 Vue 的 dist、Django 的 db.sqlite3）；系统/IDE 模板只管编辑器与系统文件。按需勾选即可，不要贪多。
重复行是怎么去重的？
按「语言 → 框架 → 系统/IDE」的顺序拼接时，内容完全相同的行只保留第一次出现的位置（如 Node 和 Python 都有 .env，只保留 Node 块里的那一行），预览区上方的统计栏会显示本次去掉了多少重复行。
勾选了 Flutter，为什么 .idea/ 还在？
Flutter 官方模板本身包含 .idea/ 等 IDE 规则；如果你同时勾选了 JetBrains 模板，重复行会被自动去重，不会写两遍。最终文件里每个规则只出现一次。
下载的文件名为什么是 .gitignore？
这就是 git 约定的文件名：放在仓库根目录即生效。Windows 下如果浏览器改了扩展名，手动改回 .gitignore 即可。
选择状态下次打开还在吗？
在。勾选状态实时存入浏览器 localStorage，刷新或下次打开会自动恢复；点「清空选择」可重置。换浏览器或清缓存后需要重新选择。
