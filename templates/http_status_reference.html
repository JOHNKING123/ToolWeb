help_outline 使用说明

怎么查：在搜索框输入码号（如 429）、英文原名（如 teapot）、中文名称或关键词（如 网关）、拼音首字母（如 cg 查「成功」），结果实时过滤；也可以点上方类别 tab 按 1xx~5xx 筛选。
看详情：点击任意卡片展开：英文原名、中文含义、常见场景、排查建议逐项列出，部分趣味状态码（如 418、451）还附有「冷知识」。
五类速记：1xx 信息响应（还没完事）、2xx 成功（成了）、3xx 重定向（去别处）、4xx 客户端错误（你的锅）、5xx 服务端错误（它的锅）。
联调技巧：先看首位数字定大类，再看具体码号；429/503 注意 Retry-After 头，401/403 先分清「没认出你」还是「不让你进」。

quiz 常见问题

这里的中文释义权威吗？
中文释义仅供参考，规范语义以 RFC/MDN 为准。本页中文名称、含义与排查建议均为自有改写、便于快速理解，遇到语义争议请查阅 RFC 规范文档或 MDN 英文原文。
搜索支持哪些方式？
四种：① 码号（如 429）；② 英文原名（如 teapot 会命中 418 I'm a teapot）；③ 中文名称或正文关键词（如 网关 会命中 502 网关错误、504 网关超时）；④ 中文名称拼音首字母（如 cg 命中 200 成功）。
418 I'm a teapot 是真的状态码吗？
是 IANA 注册表里的真实条目，出自 1998 年愚人节 RFC 2324《超文本咖啡壶控制协议》。2017 年曾有人提议删除它，遭到开发者强烈反对而保留。生产环境里看到它，多半是 API 彩蛋或反爬逻辑被触发了。
接口返回 429 被限流了怎么办？
先看响应里的 Retry-After 头，按指示退避重试（建议指数退避）；长期看要降低请求频率、加缓存、合并请求，或向服务方申请更高配额。压测时被 429 拦下是正常保护机制。
401 和 403 到底有什么区别？
401 是「没认出你」——没带凭证或凭证过期，去登录/刷新 token；403 是「认出你但不让你进」——权限不足或被规则拦截，重新登录通常没用，要去查权限配置或 WAF 规则。
