help_outline 常见问题

小写字母怎么处理？
编码时小写先转大写再查表，sos 与 SOS 编码结果一致；解码输出一律为大写。
空格和换行怎么编码？
任意连续空白（含换行）都视为词分隔，编码为 / ；行首行尾空白忽略，不产生空词。合法文本编码后再解码，可还原（小写转大写、空白归一）。
含中文或 emoji 时会怎样？
码表外字符记为非法字符，问题清单会标出该字符与原输入中第 N 个字符位置，非法字符跳过不进入输出，其余字符正常编码，不整体失败。
解码时遇到无法识别的点划串怎么办？
记为无法识别的问题，定位到词序号＋码序号并跳过该码元，其余码元照常解码。
摩斯码能用来加密吗？
不能。摩斯码不是加密：码表公开、人人可查、可逆对照，任何人拿到摩斯码都能按表还原原文，不要把它当作保密手段。
本工具会发报或播放声音吗？
不会。本工具只做标准国际摩斯码编解码，不做音频发报与无线电实操。
文本会上传到服务器吗？
不会。本工具纯前端运行，转换、复制全在浏览器本地 JavaScript 里完成，脚本中没有任何 fetch / XHR 上传逻辑，也不用 CDN。可断网使用（首次加载页面除外）。
和 Base64 编码/解码有什么区别？
Base64 是二进制编码：把二进制数据编成 ASCII 文本；摩斯码是点划编码：把文本字符编成点划对照码。编码对象与码表不同，互链文案按此区分。
