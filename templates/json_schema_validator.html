📖 支持的关键字（draft-07 核心子集）

typepropertiesrequireditemsenumpatternminLengthmaxLengthminimummaximumformat$ref（本地）
type 可取 string / number / integer / boolean / object / array / null（也支持数组形式如 ["string","null"]）；format 支持 date / time / date-time / email / uri / url / hostname / ipv4 / ipv6 / uuid（未知 format 会被忽略）；$ref 仅支持指向本文档内的本地引用（如 #/definitions/address）。
错误定位：每条错误给出 JSON Path（如 $.address.zipcode、$.hobbies[1]）+ 中文描述 + 实例中的行列，点击错误即可跳转到对应行。
互链工具：先用 JSON 解析器 格式化 JSON，用 JSON/YAML 互转 转换格式，用 文本对比 对照两个版本的实例差异。
隐私：全程无网络请求 —— 解析、校验、定位都在你的浏览器里完成，可在 DevTools Network 面板验证。
