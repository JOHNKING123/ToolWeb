SVG 波形／斑点背景生成器

做落地页、封面、海报时想要波形分隔与有机斑点背景，不用手写 SVG 路径：调参→实时预览→导出 SVG / PNG / CSS 背景代码，一次成型。

真限制，先说清楚：本工具只做装饰背景几何，不做插画编辑，也不做动画视频导出；波形只做正弦分层，不做手绘路径编辑；斑点形状由种子决定，同一参数＋同一种子输出完全一致（种子可复现），换种子即换形状；PNG 导出为画布尺寸光栅化结果，PNG 放大不如 SVG 清晰，要无损缩放请用 SVG；生成只在浏览器本地完成，不收集、不上传任何内容。

使用说明

波形模式：每层是一条正弦曲线向下闭合到底边的填充形状，层数 1–4 层，后画的层盖在前面层的上面；振幅越大起伏越大，频率是整幅宽内的完整周期数，基线是波形上下起伏的中心高度。
斑点模式：先按顶点数在圆周上均匀取点，再按圆润度做径向扰动（圆润度 0 时就是正多边形），最后用 Catmull-Rom 转三次贝塞尔平滑闭合，得到有机斑点；种子固定时形状固定，记下种子就能复现同一形状。
导出：SVG 是矢量，无损缩放；PNG 是按画布尺寸光栅化的位图，放大后不如 SVG 清晰；CSS 背景代码是 data URI 片段，粘贴到样式表的 background-image 即用。
隐私：所有生成、预览、导出都在浏览器本地完成，不收集、不上传任何内容，本页面不发起任何网络请求。

常见问题

为什么改了参数预览没变，还出现红字？
参数非法时页面会红字提示具体原因（如尺寸超出 200–4000、振幅超过高度一半、基线超出画布），且不静默改你的数值；按提示调回合法范围即可。
斑点每次刷新都一样吗？
只要参数和种子不变，输出就逐字节一致。点「换一个种子」会换一个新形状；记下种子数字，下次填回去就能复现。
PNG 和 SVG 导出该选哪个？
要无损缩放、继续编辑，选 SVG；要直接当图片用、尺寸就是画布尺寸，选 PNG。注意 PNG 放大不如 SVG 清晰。
能做动画波形或视频导出吗？
不能。本工具只做装饰背景几何，不做动画视频导出，也不支持导入已有 SVG 再编辑。
内容会上传到服务器吗？
不会。生成只在浏览器本地完成，不收集、不上传，本页面无后端调用、无外部请求。
