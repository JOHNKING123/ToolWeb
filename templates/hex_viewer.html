真限制说明

大文件仅分片读取／分页预览：文件按页分片从磁盘读取（slice 分片），不一次性载入全部字节；超过 256MB 的文件本工具拒绝打开（浏览器内存上限）。
只读查看、无编辑：本工具只能查看字节内容，不能修改文件；需要生成/转换字节请用 HEX ↔ C 数组互转器。
ASCII 列按 Latin-1 判定：ASCII 列只把 0x20–0x7E 判为可打印字符，其余显示为「.」；UTF-8 等多字节字符会显示为其字节序列（如中文显示为连续的「.」）。
全程本地、零上传：本页面零 fetch / XHR、零 CDN，文件经浏览器 File API 本地读取，字节数据不出本机。

常见问题

我的文件会被上传到服务器吗？
不会。文件经浏览器 File API 在本地分片读取，本页面零 fetch / XHR、零 CDN，字节数据不出本机。
为什么中文在 ASCII 列显示为「.」？
ASCII 列按 Latin-1 只判定 0x20–0x7E 为可打印字符；UTF-8 中文是多字节序列，每个字节都不在可打印范围内，故显示为连续的「.」。这是真限制，非乱码。
支持多大的文件？
上限 256MB；大文件按页分片读取预览，搜索也按 1MB 分块扫描，不会一次性吃掉内存。
