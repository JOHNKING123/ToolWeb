使用说明

  1. 先填 CSS 选择器（默认 .btn），再切「默认／悬停／聚焦／按下」页签，分别调六组值：背景色、边框、圆角、内边距、字体、阴影。
  2. 滑杆与数值框双向联动，可直接输入精确数值；颜色一律用取色器选择，输出为 rgba() 形式。
  3. 某态与默认态逐项一致时，页签会标注「与默认一致」，输出时自动省略该规则块，不产生空规则。
  4. 预览区是真 <button> 元素：把鼠标移到按钮上体验 :hover，按 Tab 聚焦体验 :focus-visible，按住左键体验 :active。
  5. 点「载入示例」可一键看到四态均有差异的完整例子，再按需改写；复制 CSS 或下载 button.css 后直接粘贴进样式表即用。
  6. 「下载演示页」会生成内嵌当前 CSS 的 button-demo.html，离线打开即可向他人演示三态效果。

常见问题

focus 态为什么用 :focus-visible 而不是 :focus？
:focus-visible 只在键盘聚焦等需要可见焦点环的场景生效，鼠标点击不会残留焦点样式，是更现代的做法；预览时按 Tab 键即可看到效果。
与默认一致的态被省略了，CSS 还完整吗？
完整。省略的态会继承默认态的全部声明，浏览器渲染结果与逐态写全量声明一致，只是代码更短。
想要禁用态 / 加载态怎么办？
本工具只做 hover／focus／active 三态＋默认态，不做禁用态／加载态；如需 :disabled 样式，可在输出的 CSS 后面手工追加一条规则。
我的输入会被上传吗？
不会。全部计算在浏览器本地完成，本页面零网络请求，文本不出浏览器。
