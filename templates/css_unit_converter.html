使用说明与常见问题

支持哪些单位？
14 个 CSS 长度单位：px、rem、em、vw、vh、vmin、vmax、%、pt、pc、in、cm、mm、Q。ch / ex 依赖具体字体度量，本工具不做换算；颜色、时间、角度单位也不在范围内。
em 和 rem 有什么区别？
rem 的基准是根元素字号（上面「根字号」输入），em 与 % 的基准是父级字号（上面「父级字号」输入）。点「载入示例」看 16px = 1rem（根 16）= 0.8em（父级 20）= 0.8333vw（1920 视口），同一数值在三种基准下各不相同。
为什么 vw / vh / em / % 的结果会变？
它们是相对单位：vw = 视口宽的 1%，vh = 视口高的 1%，vmin / vmax 取视口两边的较小 / 较大值，em = 父级字号倍数，% = 父级字号的百分之一。改上下文参数，对照表对应行即时重算。
绝对单位为什么是 96dpi？
按 CSS 规范：绝对单位以 96px = 1in 为基准定义（1pt = 1/72in，1pc = 12pt，1cm = 96/2.54px，1mm = 96/25.4px，1Q = 1/4mm），与设备实际 DPI 无关。所以 16px = 12pt = 1pc 恒成立。
结果保留几位小数？
最多 4 位小数，四舍五入后去尾零（如 0.166666→0.1667，1.2000→1.2）。
我的输入会被上传吗？
不会。全部计算在浏览器本地完成，本页面零网络请求、零 CDN；复制只写本地剪贴板，下载只生成本地文件。
