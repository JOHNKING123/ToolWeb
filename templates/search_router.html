🌐 OpenSearch：加为浏览器地址栏搜索引擎

Chrome / Edge（推荐，最快）：设置 → 搜索引擎 → 管理搜索引擎和网站搜索 → 添加 → 名称填「社区搜索」、快捷字词填 sr、网址填 https://www.it-tool.eu.cc/tools/search-router?q=%s → 以后在地址栏输入 sr + 空格即可直搜。
Firefox：把本页加入书签，编辑该书签设置关键词为 sr，地址栏输入 sr 关键词 直达。
标准 OpenSearch：下载上方 XML 部署到你的网站，在页面 <head> 加 <link rel="search" type="application/opensearchdescription+xml" href="…xml"> 即可被浏览器自动发现。

📖 使用说明

三步上手：① 左侧输入关键词（回车即搜）、勾选社区板块、选择时间范围；② 右侧得到各社区搜索链接，点击单条在新标签页打开；③ 赶时间可用「一键全开」批量打开，或「复制全部链接」粘贴分享。
路由规则：Reddit / Quora 走 Google site: 过滤（Google 对这两站的索引质量远胜其站内搜索）；Hacker News 走官方 Algolia 搜索（hn.algolia.com，支持日期范围）；Stack Exchange 走 stackoverflow.com/search、V2EX 走 v2ex.com/search、知乎走 zhihu.com/search?type=content 官方站内搜索 —— 彻底绕开 Google 的 AI SEO 垃圾。
时间范围：Google 链接追加 after:YYYY-MM-DD（从今天前推）；HN 链接映射为 Algolia 的 dateRange 参数（last24h / pastWeek / pastMonth / pastYear）。
地址栏直搜：本页支持 ?q=关键词 参数 —— 把它设为浏览器自定义搜索引擎后，地址栏输入即可直达本页并自动生成链接。
互链工具：关键词需要编码调试可用 URL 编解码；搜索结果筛选文本可用 正则测试（开发工具家族联动）。

❓ 常见问题

为什么不用 Google 直接搜？通用搜索结果正被 AI SEO 农场和 affiliate 站淹没；社区里的真实踩坑讨论、版本号细节、高赞回答，在站内搜索里更容易找到。
Reddit / Quora 为什么走 Google 而不是站内搜索？Reddit 站内搜索对历史内容召回差，Quora 站内搜索登录墙严重；Google 的 site: 索引反而是这两站最高质量的入口。
一键全开没反应？浏览器拦截了批量弹窗 —— 本工具会自动降级为复制全部链接到剪贴板并 toast 提示；也可以把本站加入弹窗白名单。
我的搜索关键词会上传吗？不会。链接全部在浏览器本地拼串生成，无任何网络请求，可断网使用（打开链接本身需要联网）。
OpenSearch XML 怎么用？上方文本框即标准描述文件（含 ShortName 与 ?q={searchTerms} 模板），复制或下载后按说明部署；最快的方式是直接用 Chrome 自定义搜索引擎（%s 占位）。
