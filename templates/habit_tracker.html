📅 习惯追踪器

习惯打卡/习惯追踪：多习惯管理 → 日历热力图点击打卡 → 连续打卡 streak 统计 → 本周完成率，纯本地不登录，自律养成助手

① 习惯管理

点击习惯卡片切换当前打卡习惯；每张卡片右上角可编辑（改名/改目标）或删除。数据实时存本浏览器 localStorage。

② 日历热力图

已打卡 未打卡 今天
点击任意日期格子即可勾选/取消当天打卡；打卡记录按「连续自然日」累计 streak。

③ 连续打卡统计 · 周报

④ 导入 / 导出 JSON

导出文件形如 habits_20261103_050000.json，格式为 {"habits":[{"name":"早起","target":"每天","checkins":{"2026-11-03":true}}]}；换设备/换浏览器时靠它迁移——导入会把文件里的习惯追加到现有列表（原有习惯不受影响）。

真限制（先说清楚）

  • ① 只存本浏览器：打卡数据只在 localStorage 里，跨设备不同步；清除浏览器数据/换浏览器/重装系统都会丢失——重要习惯请定期导出 JSON 备份。
  • ② 连续自然日口径：streak 按连续自然日计算，当天未打卡则从昨天起算；断档一天即重置，续上后重新计数。
  • ③ 纯本地处理：习惯与打卡记录只在你的浏览器内流转，不会上传到任何服务器（可在浏览器 Network 面板自证）。

使用说明

流程：添加习惯（名称＋周期目标，如「每天」/「每周≥5次」）→ 点击习惯卡片切换 → 在日历热力图上点今天的格子打卡（再点一次取消）→ 在「连续打卡统计」里看当前连续天数、最长连续、本周完成率。
streak 规则：连续自然日口径；当天还没打卡时，连续天数从昨天起算；断档一天归零。
备份：数据自动存本浏览器；换设备前先「导出全部习惯 JSON」，到新设备上「导入 JSON 文件」恢复。
