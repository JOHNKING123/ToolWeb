使用说明

  1. 左侧选动画类型（共 7 种 loader 预设），调尺寸（16–128px）、颜色（任意 6 位 hex）、速度（0.4–3s）、数量（点跳跃 2–5 个／柱条 3–8 条）。
  2. 中央预览区实时渲染真 .loader 元素，可切换白／深两档背景验证对比度。
  3. 右栏 CSS/HTML 页签切换代码：CSS 为 .loader 规则块＋@keyframes，HTML 为结构片段，复制后粘贴进项目即可用，零依赖。
  4. 点「下载 loader.css」保存当前类型的独立样式文件；复制 HTML 片段时记得一并带上对应 CSS。
  5. 所有生成逻辑在浏览器本地完成，非法参数（如非 6 位 hex）会以中文报错提示，绝不静默钳制。

常见问题

导出的 CSS 需要配合 JS 才能动起来吗？
不需要。所有 loader 都是纯 CSS @keyframes animation，把 CSS 和 HTML 片段放进页面就能动，零依赖、零 JS 库。
动画只做视觉提示，那真实的加载状态怎么接管？
本工具只生成视觉 loader 动画，不管理真实的异步请求状态。请求开始前显示 .loader、请求完成后隐藏，这部分逻辑需要开发者在自己的代码里接管。
为什么速度是「秒/圈」，数量有类型限制？
速度即动画时长，一圈／一周期多少秒；数量按类型限定（如点跳跃 2–5 个、柱条 3–8 条），超出会报中文错误而非静默截断。
我的输入会被上传吗？
不会。全部计算在浏览器本地完成，本页面零网络请求，文本不出浏览器。
