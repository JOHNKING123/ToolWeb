使用说明

  1. 先在「网格尺寸与间距」定列数／行数与两个 gap，再在「轨道编辑」逐条改轨道尺寸，画布与预览实时同步。
  2. 在画布上拖拽圈选一个矩形，输入区域名点「生成区域」，区域即着色；点击已命名单元格可选中，再到区域侧栏改名或清除。
  3. 点三个预设一键载入典型布局，载入后仍可改任意控件；列数／行数在 1–12 之间调整，新增行列补空、缩减裁剪。
  4. 复制 CSS／HTML 或下载 grid.css／grid-demo.html，粘贴即用；生成的网格 CSS 如需映射为工具类，走 CSS 转 Tailwind 工具。

常见问题

轨道能写 em 或 rem 吗？
不能。本工具轨道只认 fr／px／%／auto／minmax，其它单位会红字提示并拒绝，不静默转换。
区域名有什么规则？
须字母开头＋字母数字下划线连字符（如 header、chart1、main-area）；数字开头、含空格或中文都会红字提示并拒绝。
为什么 L 形区域生成失败？
每个区域须为完整矩形：区域的单元格必须恰好填满它的最小外接矩形，缺角的 L 形会被判失败并红字提示区域名。
为什么没有断点变体？
本工具只输出一组网格 CSS，不产 sm／md／lg 断点变体；多断点请在自己的样式表里用媒体查询包裹生成的代码。
能做嵌套网格吗？
不能。本工具只做单层显式网格，不做嵌套子网格／subgrid；子区域请另建一个网格。
我的输入会被上传吗？
不会。全部编辑与预览只在浏览器本地完成，本页面零网络请求，不收集、不上传任何内容。
