常见问题

backdrop-filter 和 filter 有什么区别？
backdrop-filter 模糊的是面板背后内容，filter 模糊的是元素自身。本页只做 backdrop-filter；要模糊元素自身请去 CSS 滤镜生成器。
不透明度滑杆到底改的是什么？
就是对应 rgba 的 alpha：填充不透明度改 background 里 rgba 的 alpha，边框不透明度改 border 里 rgba 的 alpha，阴影不透明度改 box-shadow 里 rgba 的 alpha。
为什么面板在某些浏览器上不模糊？
backdrop-filter 需要浏览器支持（现代 Chrome／Edge／Safari／Firefox 均已支持，老旧浏览器会直接显示半透明面板而不模糊）；代码里同时输出了 -webkit-backdrop-filter 做兼容。
数值可以写几位小数？
最多 2 位小数，例如模糊 12.5px 可以，12.555px 会红字报错，不会静默取整或钳制；超出范围、非法颜色同样报错。
我的输入会被上传吗？
不会。预览背景为页面内置渐变与图案，全部编辑与预览只在浏览器本地完成，本页面零网络请求，零上传。
