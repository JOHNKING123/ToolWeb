粘贴 / 拖拽文件名 → 规则组合 → 新旧对照预览 → 生成 bat / ps1 / sh 改名脚本下载

🔒
隐私承诺：文件名只在你的浏览器里处理，不上传服务器、不读取文件内容。
拖拽文件时仅读取 file.name（文件名），不会打开、读取或上传任何文件内容；规则计算、冲突检测、脚本生成全部在本地完成，无任何后端调用、无第三方请求。你可以在 DevTools 的 Network 面板验证 —— 没有一次网络请求。

info 功能说明

  • 📥 输入：文本框每行一个文件名粘贴；或把文件拖进虚线框（仅取文件名，不读内容、不上传）。支持去重、字母排序、清空。
  • 🔍 查找替换：普通文本全文替换，或开「正则模式」（JS 语法，替换支持 $1/$& 引用；正则非法时中文提示，不会崩）。
  • ⏮⏭ 前缀/后缀：支持 {date}（当天 YYYYMMDD）、{n}（1 起序号，3 位补零）占位符；后缀插在扩展名前面。
  • 🔢 编号：起始号、步长、位数补零、位置（前缀/后缀）、分隔符自由配。
  • 📅 日期：YYYY-MM-DD / YYYYMMDD / YYYYMMDD_HHmmss / 自定义格式，当天或固定日期，前缀/后缀位置可选。
  • 🔠 大小写：全大写 / 全小写 / 首字母大写。
  • ✂ 删字符：删除首 N 个 / 尾 N 个字符，或删除所有空格（含全角空格）。
  • ⚠ 冲突：改名后出现同名文件时标红并中文警告，冲突行自动排除在导出脚本之外（建议加一条「编号」规则消除冲突）。
  • 💾 导出：.bat 用 ren（双击运行）、.ps1 用 Rename-Item -LiteralPath（右键用 PowerShell 运行）、.sh 用 mv --（chmod +x 后执行），三者均含中文注释与特殊字符转义。
  • 📱 响应式：桌面左右双栏、移动端自动堆叠，规则卡片支持 ▲▼ 调序（触屏友好）。
