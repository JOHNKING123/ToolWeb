开始检测

本工具先通过站内已有接口 GET /tools/api/my-ip 获取你的出口 IP、归属国家与 IP 时区， 再在浏览器本地完成五项一致性/泄露检查：① 时区一致性 ② 语言-国家一致性（启发式）③ WebRTC 真实 IP 泄露 ④ 自动化信号 ⑤ Canvas/WebGL 指纹同会话稳定性。全部检查只在你的浏览器内完成，不会上传到任何服务器。

真限制（先说清楚）

  • ① DNS 泄漏本页不含：DNS 泄漏检测需要服务端配合构造检测域名，本页只做浏览器侧一致性检查，不含 DNS 泄漏项。
  • ② WebRTC 受 mDNS 保护影响：现代浏览器默认用 mDNS（.local 主机名）隐藏内网 IP，本页仅能检出仍暴露数字 IP 的情况；检测过程会向公共 STUN 服务器发起请求以收集 ICE 候选（仅用于获取候选地址，不发送个人信息）。
  • ③ 语言-国家为启发式：语言与国家的对应是启发式规则（如 en-US 用户身处国外属正常），该项只给警告不判死刑。
  • ④ 指纹仅演示稳定性：指纹哈希仅用于演示本会话内的稳定性，不做跨站追踪判定；哈希值不出浏览器。

使用说明

第一步：点击「开始检测」——先取出口 IP（国家/时区/运营商），再本地跑五项检查。
第二步：看逐项红绿灯：🟢通过 / 🟡警告 / 🔴未通过 / ⚪未知，每项附穿帮原因中文说明。
第三步：看综合评分（A 伪装良好 / B 基本过关 / C 有穿帮风险 / D 穿帮明显），「一键复制报告」可粘贴分享。
常见穿帮：浏览器时区与节点时区不一致、WebRTC 泄露真实 IP、navigator.webdriver=true 被自动化工具接管。
