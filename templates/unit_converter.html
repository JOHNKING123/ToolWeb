使用说明

长度：毫米 mm / 厘米 cm / 米 m / 千米 km / 微米 μm / 英寸 in / 英尺 ft / 码 yd / 英里 mi（1 英里 = 1.609344 千米，1 英寸 = 2.54 厘米）。
重量：毫克 mg / 克 g / 千克 kg / 吨 t / 盎司 oz / 磅 lb / 斤（市斤 = 500 克）。
温度：摄氏度 ℃ / 华氏度 ℉ / 开尔文 K；换算用公式而非倍率，绝对零度（-273.15 ℃ / -459.67 ℉ / 0 K）以下的值会被拒绝。
数据存储双口径：十进制口径按 KB = 1000 进位（硬盘厂商常用），二进制口径按 KiB = 1024 进位（操作系统/内存常用）；切换口径后单位列表与换算结果自动重算。
互链工具：数字处理常用组合 —— 进制转换器、时间戳转换、JSON/YAML 互转。
隐私：全程无网络请求 —— 换算、校验、复制都在你的浏览器里完成，可在 DevTools Network 面板验证。
