Markdown 表格转 CSV

粘贴 Markdown 即解析 GFM 表格：转义管道与对齐行正确处理，表格实时预览，一键导出 CSV，纯前端不上传

本工具只解析标准 GFM 表格：表头行＋分隔对齐行（:---／---:／:---:）缺一不可，合并单元格不支持，一次解析取输入中的首个表格；导出的 CSV 为 UTF-8 with BOM，Excel 打开中文不乱码；粘贴与本地文件读取均只在浏览器内处理，零上传、零网络请求。

输入变化时表格实时重解析、实时预览；未检测到标准 GFM 表格时给出中文提示，不输出误导性内容。

使用说明

  1. 先粘贴 Markdown：或点「读取本地 .md 文件」在本机读文件（FileReader，不上传）；输入为空或无表格时只提示，不输出误导内容。
  2. 表格口径：必须是标准 GFM 表格——表头行、分隔对齐行、数据行；对齐行每格形如 :---（左）／---:（右）／:---:（居中）／---（默认左）。
  3. 转义管道：单元格里的 \| 会还原为字面竖线，不会把一列劈成两列；首尾管道可写可不写。
  4. 预览：按每列对齐渲染 HTML 表格，全部单元格用 textContent 渲染，输入里的 HTML 只显示为文本，不会执行。
  5. 导出：一键导出保存为 markdown_table_YYYYMMDD_HHmmss.csv，UTF-8 with BOM，Excel 打开中文不乱码。
  6. CSV 转义：字段含逗号、双引号、换行时按 RFC4180 加引号并双写引号；列数不足的行自动补空。
  7. 示例：点「员工表」看常规解析，点「转义管道表」看 \| 与引号字段的还原；载入后仍可再改再导出。
  8. 互链：要反向把 CSV 生成 Markdown 表格去 CSV→Markdown 表格生成器——表格一条龙。

常见问题

为什么提示「未检测到 Markdown 表格」？
本工具只认标准 GFM 表格：表头行之后必须紧跟分隔对齐行（如 | :--- | ---: |）；缺对齐行、或表格用了合并单元格写法，都解析不了，请先改成标准写法。
单元格里的 \| 会怎样？
还原为字面竖线 |，不切分列；预览与 CSV 里都显示为单个竖线。
对齐行会影响导出的 CSV 吗？
不会。CSV 本身没有对齐概念；对齐只决定预览表格里每列的左／居中／右显示。
导出的 CSV 用 Excel 打开会乱码吗？
不会。文件带 UTF-8 BOM，Excel 直接双击打开中文正常显示；其他编辑器忽略 BOM 也不影响内容。
合并单元格的表格能转吗？
不能。这是真限制：只解析标准 GFM 表格，合并单元格不支持；一次解析取输入中的首个表格。
我的 Markdown 会被上传吗？
不会。粘贴与本地文件读取均只在浏览器内处理，零网络请求，零 CDN，本页 JS 源码无任何 fetch／XHR 调用。
