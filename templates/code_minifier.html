引擎说明：JS 引擎为自研单遍扫描器——字符串（' " `）、模板字符串 ${}、正则字面量内的 // 与 /* */ 不会被误删；换行合并时按 ASI（自动分号插入）规则补 ; 或留空格，保证语义不变；危险合并（++ -- // /* */）自动保留分隔空格。强压缩把全部代码压成一行，体积最小；轻压缩仅去注释与冗余空白、保留换行，便于调试。空输入会给出中文提示，不会报错。
