gavel 字体版权查询

一键检测电脑已装字体的版权状态：免费商用 / 需付费授权 / 高风险，并给出免费商用替代推荐；也支持批量手动输入查询。内置约 200 款常见字体离线版权库。

隐私声明：纯前端本地检测，字体列表不出浏览器。一键检测与手动查询全部在当前浏览器内完成，不会上传到任何服务器，也不会被记录或分享。打开 DevTools 的 Network 面板可验证：本页面检测过程无任何网络请求。
warning
版权准确性声明：版权信息整理自公开资料，仅供参考。字体授权政策可能随时间调整，具体以各权利方官方授权政策为准；如有商业用途需求，建议咨询专业人士或直接向权利方确认。
info
技术限制说明：一键检测采用 canvas measureText 宽度比对原理——将候选字体与系统基线字体（monospace / serif / sans-serif）的渲染宽度对比，宽度不同即判定为已安装。字形度量相近的字体可能误报或漏报，不同浏览器 / 操作系统的检测结果可能略有差异；「已安装」不等于「已获商用授权」，请以版权状态判定为准。

① 一键检测本机已安装字体

点击后自动用 canvas 探测版权库中约 200 款字体是否安装在本机，并按版权状态分组展示。

② 手动输入查询

每行输入一个字体名称（支持中英文，如「微软雅黑」「Microsoft YaHei」「方正兰亭黑」），批量查询版权状态。
报告包含检测时间、一键检测与手动查询结果分组汇总，以及版权声明，可直接粘贴到文档或发给法务 / 设计同事确认。

③ 版权库浏览 （共 0 款）

离线版权状态库：免费商用 / 需付费授权 / 高风险三档，支持关键词搜索与状态筛选。

状态说明与常见问题

免费商用：权利方明确免费授权（含 SIL OFL 等开源协议与厂商公益免费字体），个人与企业可直接用于商业用途；OFL 协议字体不可单独售卖字体文件本身。
需付费授权：商用前须向权利方购买授权；系统自带字体（宋体 / 黑体 / 楷体 / 仿宋、微软雅黑除外见下）随操作系统仅获使用许可，商业印刷与发布前建议确认授权或改用免费替代。
高风险：维权诉讼高发厂商的字体（如方正 / 汉仪 / 华康 / 造字工房 / 叶根友），以及版权归属方正的微软雅黑；商用前务必获得书面授权。
未收录：版权库暂未收录的字体，请以权利方官方政策为准。
问：检测显示「已安装」是否代表可以用？不代表。检测只判断字体是否安装在本机，能否商用请看版权状态徽章。
问：免费商用字体能用于 Logo / 商标吗？部分免费字体的授权排除 Logo 与商标注册场景，商用前请细读该字体的官方授权文本。
