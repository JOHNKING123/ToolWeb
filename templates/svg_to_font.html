help_outline 使用说明

                

                    流程：把 .svg 文件拖进虚线框（可多选批量）或粘贴 SVG 代码点「加入队列」→ 在「字形队列」里确认/修改每个字形的名称 → 填好字体族名点「开始生成字体」→ 在字形网格里检查渲染效果 → 下载 TTF/OTF、复制 CSS 用到项目里。

                    解析范围：提取 <path> 的 d 属性（单个文件内多 path 合并为一个字形）；基本形状 rect/circle/ellipse/line/polyline/polygon 自动转 path；支持全部 path 命令（含 A 圆弧转三次贝塞尔）；transform 仅支持 translate/scale（不支持的会提示并忽略）；渐变/滤镜/遮罩等非轮廓元素会被忽略并提示。

                    归一化：按 viewBox（无则取 width/height）缩放到 1024 em 方框，并做 Y 轴翻转（SVG y-down → 字体 y-up），保证字形正立。

                    码点与字形名：自 U+E000 起按队列顺序分配 Private Use Area 码点；字形名由文件名清洗（非法字符转下划线、数字开头加 icon_ 前缀、重名自动加后缀）。

                    两种字体：TTF 为真正的 TrueType 轮廓（glyf 表，页面内建组装器生成）；OTF 为 CFF 轮廓（opentype.js 2.0.0 组装，随页面静态加载、无 CDN）。两者内容一致，按需选用。

                    注意：字体只保留「填充轮廓」，描边（stroke）粗细不会被转换——描边图标请先在设计软件里执行「描边转轮廓/扩展外观」。

                    坏文件处理：解析失败的文件会标红并给出原因（如「未找到可转换的矢量轮廓」），不影响队列里其他文件。

                    隐私：全部在浏览器本地完成，SVG 内容不会上传到任何服务器；预览用的 blob 链接在重新生成时自动回收。
                

            


            

                
quiz 常见问题

                

                    
SVG 会被上传到服务器吗？

                    
不会。解析、字体组装、预览、下载全部在浏览器本地执行，Network 面板里没有任何上传请求。opentype.js 2.0.0 是随页面一起静态加载的本地文件（/tools/static/vendor/opentype.min.js），不是运行时从 CDN 拉的。

                    
生成的 TTF 和 OTF 有什么区别？

                    
两者字形内容一致：TTF 是 TrueType 轮廓（glyf 表，兼容性最广，为主下载项）；OTF 是 CFF 轮廓（opentype.js 2.0.0 组装）。日常 Web 使用选 TTF 即可；需要 PostScript 轮廓流程（如特定印刷/设计软件）时选 OTF。

                    
为什么我的图标在字体里显示为实心块或缺了一块？

                    
多半是原 SVG 用了描边（stroke）表现线条——字体只保留填充轮廓，描边会被丢弃。请先在 Illustrator / Figma / Inkscape 里把描边「扩展为轮廓」（Outline Stroke）再导入。

                    
支持哪些 SVG 特性？

                    
支持全部 path 命令（含圆弧 A）、rect/circle/ellipse/line/polyline/polygon、translate/scale 变换、嵌套分组。不支持：渐变/滤镜/遮罩/裁剪（忽略并提示）、rotate/skew/matrix 变换（忽略并提示）、<text> 文本（请先转曲）。

                    
码点可以自己指定吗？

                    
当前版本按 U+E000 起顺序自动分配，保证不冲突。如需自定义码点，可下载后用 FontForge 等工具再调整。

                    
一次能转多少个图标？

                    
数量不限，队列逐个顺序解析。几十个常规图标一般在 1 秒内完成组装；单个超大 SVG（几 MB 级复杂路径）会慢一些。
