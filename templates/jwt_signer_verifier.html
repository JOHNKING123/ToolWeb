info 功能说明

            
    
                
  • ✍️ 签发：HS256 / HS384 / HS512 / RS256 四种算法，alg 由算法选择锁定，防手写错配
    • 
                
  • 📝 声明快捷插入：iss / sub / aud / iat / nbf / exp / jti 一键写入 Payload，另有「1 小时后过期」快捷按钮
    • 
                
  • 🔑 密钥安全：HS Secret 强制最小长度（32/48/64 字节），不足拒绝签发；RS256 私钥 PEM 本地导入或一键本地生成 2048 位密钥对
    • 
                
  • 🔍 验证三态：签名有效 ✓ / 签名无效 ✗（说明可能原因）/ 未签名警告（alg:none 或空签名段显式警示）
    • 
                
  • ⏳ 有效期徽章：exp 已过期 / nbf 未生效自动标注，附带本地时间换算
    • 
                
  • ⚠ 恶意示例：一键载入 alg:none token，直观感受弱算法风险
    • 
                
  • 🔒 零上传：签名验签全走浏览器 Web Crypto API，无后端调用、无外部请求，断网可用
    • 
                
  • 📱 响应式：桌面双栏、移动端自动堆叠，均可完整操作
