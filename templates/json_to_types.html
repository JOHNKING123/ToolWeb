使用说明

                

                    怎么用：把接口返回的 JSON 粘贴到左侧（或点「填充示例」），右侧即刻生成 TypeScript interface 与 Go struct，切换 Tab 查看，根类型名可自定义。

                    推断规则：嵌套对象拆分为按路径 PascalCase 命名的独立类型（如 address → RootAddress）；对象数组合并全部元素取字段并集，部分元素缺失的字段推断为可选（TS ? / Go ,omitempty）；混合类型数组生成 TS 联合类型、Go []interface{}；空数组为 unknown[] / []interface{}；null 并入 TS 联合、Go 用 interface{}。

                    隐私：纯前端本地处理，JSON 只在你的浏览器里流转，不上传服务器。
