字体搭配预览

标题与正文字体怎么配才好看？10 组预设搭配一键切换，也可手动选字体、调字号行距，实时预览中英文混排效果，满意后一键复制 CSS 直接用。

隐私声明：全程浏览器本地计算，零上传、零外部接口。搭配选择、预览渲染与 CSS 生成全部在当前浏览器内完成，不会上传任何内容，也不会请求任何外部接口。打开 DevTools 的 Network 面板可验证：本页无任何网络请求。
真限制（请先了解再使用）：
  • 仅系统字体栈：本页搭配全部基于系统自带字体栈，不加载任何网络字体；不同操作系统 / 浏览器上同一字体的渲染效果可能不同。
  • 搭配为审美建议：预设搭配是排版审美建议，不保证适用于所有场景与品牌调性，请结合实际内容判断。
  • 商用前查版权：系统自带字体不等于免费商用，商用前请先核对字体授权（见下方互链：字体版权查询）。
  • 本页零上传：不上传、不保存、不记录任何内容，关闭页面即无痕迹。

① 预设搭配

10 组预设搭配，覆盖经典 / 现代 / 优雅 / 活泼 / 极简五种风格，点击卡片即选用。

② 手动选择字体

不满意预设？直接给标题和正文各挑一个字体栈，实时生效；选回「跟随预设搭配」即恢复当前预设。

③ 字号与行距

拖动滑杆即时生效：标题 16–72px，正文 12–24px，行距 1.2–2.0。

⑤ 复制 CSS

直接可用的两段 CSS：.font-title 用于标题，.font-body 用于正文，粘贴进样式表即可。
