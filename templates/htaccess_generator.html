使用说明

                

                    怎么用：勾选分组开关（或点一键预设），右侧结果实时更新；点「复制 .htaccess」粘贴到网站根目录，或点「下载 .htaccess」直接保存文件。

                    顺序为什么固定：HTTPS 强制跳转与 www 归一必须在其它改写规则之前，否则容易循环重定向；生成器按正确顺序输出，不许拖乱。

                    上传前三件事：① 备份现有 .htaccess；② 确认主机是 Apache 且 AllowOverride All 已开启；③ 上传后访问 http:// 旧地址验证是否 301 到 https://，再清缓存复查。

                    301 行怎么写：源路径以 / 开头（如 /old-page.html），目标写完整 URL（如 https://example.com/new-page.html）；空行、缺 / 的行生成时自动跳过，不会输出残行。

                    防盗链注意：白名单域名按行填写，生成器会把点号转义进正则；勾选「允许空 Referer」时直接打开图片不受影响，取消则空 Referer 也返回 403。

                    纯前端：所有生成、复制、下载都在你的浏览器本地完成，不发起任何后端请求、不上传任何内容，断网也能用。
                

            


            

                
常见问题

                

                    
生成的规则在 Nginx 上能用吗？

                    
不能。本工具只输出 Apache 2.4 语法（mod_rewrite／mod_headers／mod_expires），Nginx 配置语法完全不同，照搬会直接报错；Nginx 用户请按等价语义重写 server 块。

                    
粘贴后规则没生效，怎么排查？

                    
先确认三点：① 主机是 Apache 而非 Nginx；② 虚拟主机主配置里 AllowOverride All 已开启（未开启时 .htaccess 会被静默忽略，这是最常见原因）；③ 文件确实放在网站根目录且文件名为 .htaccess（不是 .htaccess.txt）。仍无效时看 Apache error_log。

                    
为什么 HTTPS 跳转和 www 归一要排在最前面？

                    
改写规则按顺序执行：先统一协议和域名，后面的 301、防盗链才不会在 http／带 www 的旧地址上重复触发；顺序乱了容易出现循环重定向（ERR_TOO_MANY_REDIRECTS）。生成器把顺序写死，不用你操心。

                    
同时勾选「统一 www」和「统一去 www」会怎样？

                    
不会同时发生：www 归一是单选按钮组，同一时间只能选一种，生成结果里也只会出现对应的一条规则，另一条绝不会输出。

                    
覆盖原文件前为什么要备份？

                    
很多主机商、WordPress 插件会在 .htaccess 里写自己的规则，直接覆盖会丢配置。先把原文件另存为 .htaccess.bak，再把生成内容合并进去（或确认无原规则后再整文件替换）。

                    
复制失败怎么办？

                    
浏览器剪贴板权限被拒时页面会弹出降级提示：手动选中上方输出文本，按 Ctrl+C 复制即可；也可以点「下载 .htaccess」直接保存文件再上传。
