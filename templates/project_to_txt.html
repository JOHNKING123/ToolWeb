help_outline 使用说明

三步上手：① 把项目文件夹拖进虚线框（或点「选择文件夹」）；② 在文件树里确认勾选 —— node_modules/.git/dist 等已自动剔除，二进制文件标黄跳过；③ 点「生成打包文本」，一键复制后粘贴到 ChatGPT / Claude / Gemini / Kimi 的输入框即可。
输出格式：顶部是汇总头（文件数、总字符数、预估 Token、生成时间），每个文件以 ====…==== 分隔线 + FILE: 相对路径（N 字符） 开头、全文紧随其后，LLM 能清晰分辨文件边界。
Token 预估：按 ASCII 约 4 字符 / 中日韩字符约 1.5 字符折算，为启发式估算，实际以各模型 tokenizer 为准；超长项目建议分模块多次打包。
大文件保护：单个文件超过 1MB 自动跳过（常见于误选的日志、bundle 产物），避免一次生成几十万字符卡死页面。
适用边界：本工具只做「文本合并」，不会执行代码；含密钥的 .env 文件默认会被打包，喂给 LLM 前请自行剔除或脱敏。
「开发一条龙」：仓库刚搭好缺忽略规则？先用 .gitignore 生成器 生成忽略文件；正则写不准？用 正则表达式测试 在线验证 —— 配环境、验表达式、打包喂 AI，一套流程走完。

quiz 常见问题

文件夹内容会上传到服务器吗？
不会。遍历、过滤、合并全在浏览器本地的 JavaScript 里完成，页面脚本中没有任何 fetch / XHR 上传逻辑，你可以在开发者工具 Network 面板验证，也可以断网使用（首次加载页面除外）。
为什么 node_modules / .git / dist 被自动忽略了？
这些是依赖、版本历史与构建产物，喂给 LLM 只会浪费 token。默认忽略目录为 node_modules、.git、.idea、.vscode、dist、build、__pycache__，外加 *.lock 锁文件与系统垃圾文件（.DS_Store / Thumbs.db）；可在「打包设置」里增删，改完点「应用设置」即时重新分类。
图片、压缩包这些二进制文件怎么处理？
按「扩展名 + 文件头魔数 + NUL 字节」三重识别自动跳过，并在文件树中以黄色「二进制跳过」标签标注（含识别依据，如 PNG / ZIP / .exe），不会混入文本。
单个文件超过 1MB 会怎样？
自动跳过并标注「超 1MB 跳过」，不计入打包结果。这是为了防止误选的日志文件或打包产物一次生成几十万字符、卡死页面或爆掉 LLM 上下文。
预估 Token 准确吗？
是启发式估算：ASCII 按约 4 字符/token、中日韩字符按约 1.5 字符/token 折算。不同模型的分词器有差异，实际值以模型方为准；当估算值接近模型上下文上限时，建议分模块多次打包。
扩展名白名单怎么用？
在「打包设置」里填写如 js,ts,vue，则只打包这些扩展名的文本文件。留空表示不过滤。注意白名单模式下无扩展名的文件（如 Makefile）会被排除。
生成后的 TXT 怎么喂给 LLM？
点「一键复制全文」，粘贴到 ChatGPT / Claude / Gemini / Kimi 等任意对话输入框，附一句「请基于以下项目代码回答…」即可。文件较大时建议下载 .txt，通过支持文件上传的模型直接上传附件。
哪些浏览器可以用？
Chrome / Edge 完整支持系统文件夹选择器（File System Access API）与拖拽；Firefox / Safari 自动降级为传统目录选择（webkitdirectory），功能一致。
