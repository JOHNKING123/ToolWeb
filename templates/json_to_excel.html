JSON 转 Excel

粘贴 JSON 文本或上传 .json 文件，嵌套自动展平为点路径列，一键导出 .xlsx；纯浏览器本地处理，数据零上传

真限制（如实说明，请先看）：
① 仅支持数组/对象结构 JSON——纯字符串、数字等原始类型会明确报错，无法转成表格；
② 嵌套对象/数组会展平为点路径列名（如 user.address.city、tags.0），列名即路径，不可改回嵌套结构；
③ 各行列不一致时按全部列求并集，缺失单元格留空；
④ 超大 JSON 有内存上限：输入文本 ≤20MB、数据行 ≤50000 行，超限请拆分后重试；
⑤ 纯本地解析＋本地 xlsx 库，零上传（可在浏览器 Network 面板自证：无任何外部请求）。

表格预览（请先核对）

导出文件：单 sheet「Sheet1」，列宽按内容自动调整；文件名 json_to_excel_YYYYMMDD_HHmmss.xlsx；数字存为真实数值、布尔存为布尔值、缺失单元格留空；列头为你在上方设定的列名。注：所用 SheetJS 社区版不支持写单元格样式，表头加粗/底色在导出的文件中不生效，但数值与文本类型正确。超长整数 ID（如 17 位订单号）在 JSON.parse 阶段即已丢失精度，导出无法挽回——如需保真请先把 ID 改成字符串。

使用说明

怎么用：把接口返回、日志里的 JSON 数组粘贴进来，或上传 .json 文件 → 点「解析并预览」→ 在列管理里勾选要导出的列、改列名、↑↓ 排序 → 核对分页预览 → 点「导出 .xlsx」下载。
展平规则：嵌套对象按 父.子 展开（如 user.address.city），数组按索引展开（如 tags.0、tags.1）；空对象/空数组不产生列；各行的列取并集，某行缺失的列留空。
报错定位：JSON 写错了会给出「第 X 行第 Y 列」定位，并贴出出错行前后文，方便对照修正。
隐私：解析、预览与导出全程在你的浏览器里完成，文本只在浏览器内存里流转，不经过任何服务器；xlsx 生成库为本站本地副本（static/js/vendor/xlsx-0.18.5.umd.js），无任何外部请求，Network 面板可自证。
适用边界（如实说明）：JSON 里的超大数字 ID 解析即丢精度（见上）；5 万行以上或 20MB 以上的 JSON 请拆分；列名里的点号即路径分隔符，无法区分「本来就叫 a.b 的键」。
📊 表格数据一条龙：手里是 CSV 想先转 JSON，用 CSV⇄JSON 互转；转好的 JSON 回到本页一键进 Excel；AI 回答里的 Markdown 表格想进 Excel，用 Markdown 表格转 Excel；从网页／Excel 复制的表格文本想先转标准 CSV，用 网页表格粘贴转 CSV —— 互转、预览、进表，一套流程。
