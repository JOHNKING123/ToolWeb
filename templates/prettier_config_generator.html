    常见问题
    
                
    
                    
    生成的 JSON 能直接用吗？
    
                    
    能。输出是标准 JSON（2 空格缩进），保存为项目根目录的 .prettierrc.json 后，编辑器与 Prettier 命令行即可按此配置格式化。
    
                    
    为什么只有 14 项，没有 overrides、插件配置？
    
                    
    本工具只覆盖常用核心选项子集；overrides（按文件类型覆盖）与插件配置不在本轮范围，完整选项请查 Prettier 官方文档。
    
                    
    能把已有的 .prettierrc 粘贴进来回填表单吗？
    
                    
    不能。本轮不读取、不解析现有配置；需要迁移旧配置时请对照 14 项手动勾选。
    
                    
    trailingComma 的 all／es5／none 有什么区别？
    
                    
    all 在所有可加尾逗号的地方都加（含函数参数）；es5 只在 ES5 语法合法的地方加（对象、数组等）；none 全不加。Prettier 3 默认 all。
    
                    
    bracketSameLine 和旧版的 jsxBracketSameLine 是同一个吗？
    
                    
    是同一个选项的 Prettier 3 命名：旧版叫 jsxBracketSameLine，Prettier 3 起改名 bracketSameLine 并适用于 HTML 等更多场景，本工具按 Prettier 3 口径输出。
    
                    
    我的配置会被上传吗？
    
                    
    不会。选项到 JSON 的生成全在浏览器本地完成，零网络请求，零 CDN，本页 JS 源码无任何 fetch／XHR 调用。
