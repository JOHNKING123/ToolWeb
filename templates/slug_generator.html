使用说明

1. 在输入框粘贴或键入文章标题，slug 即时生成：英文转小写、去重音（Café→cafe），中文按拼音转写（工具网站→gong-ju-wang-zhan），空白与标点统一变成选定的分隔符。
2. 分隔符选连字符（-，SEO 常用）或下划线（_）；最大长度按单词边界截断，避免把单词拦腰斩断；拼音开关关闭则中文直接删除。
3. 有几十上百个标题要处理时，用多行批量模式：每行一个标题，一键复制全部或下载 slugs.txt。
4. 生成后先用 OG 社交卡片预览 看看同一标题分享到社交平台长什么样（标题 slug ↔ 社交分享卡片，营销工具双链路）；slug 里若含特殊字符需要整体编码，用 URL 编码/解码 处理。

常见问题

slug 里为什么没有大写字母？URL 路径习惯全小写，避免大小写敏感服务器出现两条不同链接，本工具统一转小写。
中文为什么转成拼音而不是保留汉字？汉字 URL 在分享、复制时会变成冗长的 % 编码，可读性差；拼音 slug 短、可读、兼容性好。如需保留汉字请用原文做路径，本工具不做此转换。
某个汉字转出来不对或被删了怎么办？内置字表只覆盖常用字，多音字取最常用读音；表外字会被删除并提示。请按真限制说明人工复核，必要时手动改写。
最大长度截断为什么有时候比设定值短？按单词边界截断：在限制长度内找最后一个分隔符截断，保证不断开单词，所以实际长度 ≤ 设定值。
下划线和连字符哪个对 SEO 更友好？Google 明确把连字符当词分隔符、下划线当词内字符，SEO 场景建议用连字符（默认）。

真限制说明

  • 拼音基于内置常用字表，表外字删除须人工复核：字表只覆盖常用汉字，多音字取最常用读音；不在表中的字会被直接删除并在页面提示，请逐一复核，重要标题建议手动确认拼音。
  • 仅规范化 URL 路径片段：本工具只生成可直接拼进路径的 slug 片段，不处理协议、域名、查询参数；整条 URL 的编码请用 URL 编码/解码工具。
  • 纯前端本地生成：转换在当前浏览器完成，零 fetch/XHR、零 CDN，标题内容不出浏览器；不同浏览器对极少数生僻字符的 NFKD 规范化可能有细微差异。
