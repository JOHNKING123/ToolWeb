help_outline 常见问题

我填的内容会上传到服务器吗？
不会。本工具纯前端运行：表单录入、模板渲染、打印导出、草稿暂存（localStorage，key 为 tw_resume_builder_v1）全部在你的浏览器本地完成，没有任何后端请求，简历内容不出你的电脑，可打开开发者工具 Network 面板验证。
怎么把简历导出成 PDF？
点右上角「打印 / 导出 PDF」，在系统打印对话框的目标打印机里选「另存为 PDF」（或 Microsoft Print to PDF），页边距选默认，即可得到 A4 版式 PDF。打印样式已做 A4 优化：只输出简历页，编辑区、导航栏不会出现在 PDF 里。
模板可以随时切换吗？内容会丢吗？
可以。4 套模板（简约商务 / 现代双栏 / 学术严谨 / 创意配色）点一下即时切换，所有填写内容完整保留，刷新页面也不丢（自动暂存到本机）。
打印出来会有几页？
预览区上方会显示按 A4 密度估算的页数。建议把简历控制在一页：经历条目用「动作动词＋量化结果」精简表达，技能与荣誉只留最相关的。内容实在多时浏览器会自动分页。
简历生成后，怎么检查写得好不好？
用站内的简历预检工具：粘贴简历纯文本＋目标岗位 JD，一键诊断 JD 关键词匹配度、ATS 友好度、经历逻辑链与简历雷区，和本工具形成「生成→诊断」闭环。
换电脑或清理浏览器数据，草稿会丢吗？
会。草稿只存在本机浏览器 localStorage 里，换电脑、重装浏览器或清理站点数据都会丢失。定稿后建议立即导出 PDF 存档（网盘/邮箱各存一份）。
