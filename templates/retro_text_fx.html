使用说明

  1. 在「文字」区输入内容，或点「载入示例」一键填入示例文字。
  2. 点 8 种预设一键切换风格：彩虹渐变、粗描边、长阴影、3D 立体、霓虹辉光、金属铬渐变、复古褪色、双色叠印。
  3. 拖五个参数滑杆微调：渐变方向、阴影距离、模糊、描边宽度、辉光强度，预览实时同步。
  4. 选背景色或勾选透明底；霓虹、金属铬建议用深色底，双色叠印建议用白色底。
  5. 点「下载 PNG（1x/2x）」保存图片，或「复制 PNG 到剪贴板」直接粘贴到别处使用。
  6. 要给文字加 CSS 阴影去 CSS 文字阴影生成器；要给文字做渐变填充代码去 CSS 渐变生成器。

常见问题

预设可以微调吗？
可以。五个滑杆（渐变方向／阴影距离／模糊／描边宽度／辉光强度）都是在该预设默认值基础上调；想回到起点就再点一次预设按钮。
导出的 PNG 有多大？
画布按文字实际尺寸自动生成，2x 为双倍分辨率，适合印刷与高清屏；透明底导出保留透明通道。
为什么中文和英文看起来粗细不一样？
中文渲染效果依赖操作系统自带的中文字体（见下方真限制说明），不同系统的默认中文字重不同，这是正常的。
复制 PNG 没反应？
复制 PNG 依赖浏览器的 Clipboard API，旧浏览器或非安全上下文不支持，此时页面会明确提示改用下载 PNG。
我的文字会被上传吗？
不会。渲染与导出全部在浏览器本地完成，本页面零网络请求，文字不出浏览器。

真限制说明

真限制一：canvas渲染浏览器差异——同一份参数在不同浏览器／系统下可能存在细微差异（字体度量、抗锯齿、渐变插值均为各浏览器自行实现），导出前请以本机预览为准；真限制二：中文字体依赖系统——中文显示效果依赖操作系统自带的中文字体，本页不内嵌、不加载任何外部字体文件，换台电脑可能看起来不一样；真限制三：PNG本地生成不上传——渲染与导出全在浏览器本地完成，零网络请求；复制 PNG 到剪贴板依赖浏览器 Clipboard API，不支持时会明确提示改用下载。
