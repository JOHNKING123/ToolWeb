📂 文件夹对比

拖拽 / 选择两个文件夹 → 递归对比 → 新增 / 删除 / 修改三态高亮 → 导出差异报告

🔒
隐私承诺：只读取文件名、文件大小和修改时间，不读取文件内容，不上传任何数据。
文件夹扫描与对比全程在你的浏览器本地完成，无任何后端调用、无第三方请求。你可以在 DevTools 的 Network 面板验证 —— 没有一次网络请求。文件夹选择优先使用浏览器原生的 showDirectoryPicker（文件不离开本机）。

📖 对比规则说明

  • 三态分类：删除 仅 A 侧有（旧版有、新版没了） / 新增 仅 B 侧有（新版多出来的） / 修改 两侧都有但大小或修改时间不同；完全一致的记为 相同（默认隐藏，可勾选显示）。
  • 空目录纳入对比：Chrome/Edge 下用系统目录选择器可识别空目录（计入新增/删除/相同）；降级到文件夹上传控件时浏览器不暴露空目录。
  • 路径归一化：以相对路径为键，统一 / 分隔符；拖入单个文件夹时自动去掉顶层文件夹名，使 A/B 根对齐。
  • 对比选项：「忽略文件名大小写」适配 Windows/macOS 大小写不敏感场景；「只比较大小」忽略 mtime（跨机器拷贝常导致 mtime 全变）；「排除隐藏文件」跳过 .git/、.DS_Store 等。
  • 性能：扫描按批次让出 UI 线程并显示进度，上千文件不卡顿；列表一次性拼接渲染，搜索防抖。
  • 导出：.md 报告含统计与三态分组明细表，.csv 含路径/状态/两侧大小与修改时间，文件名带时间戳。
  • 📱 响应式：桌面双栏、移动端自动堆叠，触屏可点选、对比、导出。
