hide_source .env 脱敏生成器

粘贴 .env 文本或上传 .env/.txt 文件，KEY 保留、敏感值清空或占位符替换，实时生成可分享的 .env.example。

info
真限制请先看清：本工具仅做格式脱敏，无法判断密钥有效性，也不验证值是否真为密钥；脱敏后的 .env.example 里 KEY 命名仍暴露结构信息（如 DB_HOST= 表明你用数据库），分享前请自行确认；多行值可能处理不全，复杂转义请核对输出。粘贴文本只在浏览器本地处理、不上传；建议用占位值演练，勿粘贴真实生产密钥。

input 粘贴 .env 文本或上传文件（输入即实时脱敏）

文件通过浏览器 FileReader 在本地读取，不上传到服务器。解析口径：按行切分（兼容 CRLF），export 前缀剥离，键名须为字母或下划线开头、仅含字母数字下划线；双引号值解码转义、单引号值原样、无引号值以“空格 + #”截断行内注释；非法行原样保留并在行首标注 # [跳过]，不丢数据。

tune 脱敏选项

值清空模式：DB_PASS=s3cr3t → DB_PASS=；占位符模式：→ DB_PASS=YOUR_VALUE_HERE（占位符可自定义，仅占位符模式生效）。注释与空行默认原样保留，关闭后输出只剩 KEY=… 行与 # [跳过] 标注行。

help_outline 常见问题

值清空和占位符替换怎么选？
占位模板发给同事/写部署文档，两种都行：值清空得到最干净的 KEY= 骨架；占位符替换（KEY=YOUR_VALUE_HERE）更显眼，提醒填写者“这里要填值”。占位符可自定义，如 <FILL_ME>。
非法行会丢失吗？
不会。行内没有 =、键名非法、引号未闭合的行会原样保留，并在行首标注 # [跳过]，你自己决定删还是修 —— 建议先去 .env 解析与校验器 看逐行定位的报错说明。
脱敏后的 KEY 会泄露信息吗？
会。DB_HOST= 这类键名本身就暴露了技术栈与结构信息，脱敏只隐藏值不隐藏键。分享前请确认键名列表可以公开。
文本会上传到服务器吗？
不会。本工具纯前端运行，解析、脱敏、复制、下载全在浏览器本地 JavaScript 里完成（文件上传走 FileReader 本地读取），脚本中没有任何 fetch / XHR 上传逻辑。可断网使用（首次加载页面除外）。
和「.env 解析与校验器」有什么区别？
解析校验器做的是格式体检：非法行定位、重复键、空值警告，输出规整键值表。本工具做的是脱敏分享：KEY 保留、值清空或占位符替换，输出可直接分享的 .env.example。两者双向互链，流程一条龙。
