引擎说明：自研轻量 shell 词法切分——单/双引号、反斜杠转义、$'...' ANSI 引号、行尾续行 \ 均可正确处理；参数映射覆盖 -X/--request、--url、-H、-d/--data/--data-raw/--data-binary/--data-ascii/--data-urlencode、--compressed、-u、-b、-A、-k、-F/--form、--max-time。
代码生成规则：data 为合法 JSON → json=（requests 自动设置 Content-Type）；普通表单 → data=；-F 文件上传 → files=；-k → verify=False 并附中文安全警告；GET 携带 data 会提示改用 params=。未知参数一律进入诊断列表并写入代码注释，绝不静默丢弃。
等价性说明：生成的 requests 调用与原 cURL 命令语义等效（方法/URL/请求头/Cookie/请求体/超时/证书校验）；纯展示类选项（如 -s、-v、-o）会在代码注释中列出，请按需手动处理响应保存。
