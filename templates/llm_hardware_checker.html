memory 本地 LLM 硬件检测器

想在本地跑大模型，不知道显卡带不带得动、该下哪个量化版本？本页自动检测你的 GPU 型号（或手动选择显卡＋显存档位），对照数据表告诉你 7B / 14B / 32B / 70B 各量化版本能不能跑：绿灯流畅、红灯带不动，另附 tokens/s 区间参考与「想跑 70B Q4 要多少显存」的反向查询。

assessment 第三步：看推荐结果

三档含义：🟢 需求 ≤ 可用显存 × 85%，权重＋常规上下文可全量进显存；🟡 刚好装下（建议小上下文/低并发）或需部分层 offload 到内存（会很慢）；🔴 显存远不够。量化版本数字越小文件越小、速度越快，但精度损失越大：日常用 Q4_K_M 是平衡点，显存紧张试 Q3/Q2，显存充裕上 Q5/Q6/Q8。

help_outline 使用说明

流程：页面加载会自动检测 GPU（走 WebGL，不上传）→ 在第二步确认型号与显存档位（选型号会自动预填显存，可手动改；不知道型号可直接按显存估算）→ 第三步看各模型档位的红黄绿推荐。
怎么选量化：Q4_K_M 是最常用的平衡点；Q8/Q6/Q5 精度更高但更吃显存；Q3/Q2 能把大模型塞进小显存，但回答质量下降明显，只建议显存实在不够时尝试。
显存构成：本页「约需显存」= 模型权重＋常规 2k–4k 上下文开销；开长上下文、多并发或大 batch 会显著增加占用，KV 缓存量化也能省一部分。
24GB 想跑 70B？70B Q4 全量进显存约需 41GB，24GB 单卡只能把部分层 offload 到内存（黄灯「能跑但慢」，约几 tokens/s）；想流畅跑 70B Q4，建议可用显存 ≥ 48GB（多卡、工作站卡或 96GB+ 统一内存的 Mac）。
AMD / Intel 显卡：llama.cpp 与 Ollama 对 AMD（ROCm/Vulkan）与 Intel Arc 的支持在持续完善中，同显存下实际体验可能弱于 NVIDIA，推荐结果按显存口径给出，驱动与框架版本请保持最新。
隐私：全部数据内置在页面脚本中，检测与计算都在浏览器本地完成，零 fetch/XHR，不上传任何数据。

quiz 常见问题

WebGL 检测的原理是什么？会上传我的硬件信息吗？
通过 WEBGL_debug_renderer_info 扩展读取浏览器的渲染器字符串（如 "ANGLE (NVIDIA, NVIDIA GeForce RTX 4060…)"），在本地对照显卡表匹配型号。整个过程不发起任何网络请求、不上传，Network 面板可验证。注意 WebGL 读不到显存容量，显存档位需要你手动确认。
浏览器禁用了 WebGL / 检测不到怎么办？
页面会自动降级：检测区提示手动选择，你在第二步选品牌→型号→显存（或直接按显存估算），推荐引擎不受影响，不会报错或卡死。
为什么 Apple Silicon 要按 70% 折算？
Mac 是统一内存架构，CPU/GPU/系统与其他应用共享同一内存池，并非全部内存都能分给模型。按统一内存 × 70% 折算是保守经验值：比如 16GB 统一内存的 Mac 按约 11.2GB 可用显存评估，跑 7B Q4_K_M（需 4.5GB）是绿灯。
tokens/s 区间准吗？
仅供横向比较。不构成性能承诺：实际速度因显卡代际、量化版本、上下文长度、推理框架（llama.cpp / Ollama / vLLM）与采样设置差异很大。区间上限取自较新高端显卡、较低上下文的常见报道，下限偏保守；RTX 30 系用户建议按下限看，40/50 系可往上限看。
8GB 显存（如 RTX 4060）能跑什么？
7B 的 Q4/Q5 量化是绿灯（流畅）；14B Q4（需约 9GB）是黄灯「能跑偏慢」；70B 全红灯。这是本页推荐引擎按三档规则算出的结论，你可以直接在上方选 8GB 验证。
量化版本 Q4_K_M / Q8 / Q2_K 有什么区别？
数字越小压缩越狠：Q8 接近原始精度但文件大、吃显存；Q4_K_M 是社区最常用的平衡点；Q2/Q3 能把 70B 塞进 24GB 级显存（配合 offload），但精度损失明显。同一规模下显存不够就降量化，显存充裕就升量化。
这个页面会联网或上传数据吗？
不会。显卡表、模型表、推荐逻辑全部内置在页面脚本里，检测与计算都在浏览器本地完成，零 fetch/XHR，你可以在开发者工具 Network 面板验证。
