使用说明

  1. 先在「容器控件」选 direction／wrap／主轴与交叉轴对齐方式，拖 gap 滑杆调间距，预览与代码实时同步。
  2. 点击预览中的彩色编号块，或用「当前条目」下拉选中条目，再调 grow／shrink／basis／order／align-self，改动即同步预览与代码。
  3. 点四个预设一键载入典型布局，载入后仍可改任意控件；条目数在 1–12 之间调整，新增条目取默认值。
  4. 复制 CSS／HTML 或下载 flexbox.css／flexbox-demo.html，粘贴即用；生成的 flex CSS 如需映射为工具类，走 CSS 转 Tailwind 工具。

常见问题

direction 切换后主轴／交叉轴怎么变？
row／row-reverse 时主轴水平，justify-content 管水平、align-items 管垂直；column／column-reverse 时主轴垂直，两者互换，页面上方的示意文案会同步变化。
basis 能写 em 或 rem 吗？
不能。本工具 basis 只认 auto、0、数值 px、数值 %，其它单位会红字提示并拒绝，不静默转换。
为什么没有断点变体？
本工具只输出一组容器＋条目 CSS，不产 sm／md／lg 断点变体；多断点请在自己的样式表里用媒体查询包裹生成的代码。
生成的 flex CSS 能直接变 Tailwind 类吗？
本工具不直接生成 Tailwind 类；生成的 flex CSS 可再经 CSS 转 Tailwind 工具映射为工具类。
我的输入会被上传吗？
不会。全部编辑与预览只在浏览器本地完成，本页面零网络请求，不收集、不上传任何内容。
