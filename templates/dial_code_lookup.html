五条真限制

1. 区号以 ITU E.164 国家区号为准：本表区号以 ITU E.164 国家区号为准，开发轮逐条核对，核对日期 2026-11-07；个别国家／地区区号变更时以运营商／ITU 公布为准。
2. +1、+7 等区号由多国共享：+1（北美编号计划：美国、加拿大及加勒比等地）、+7（俄罗斯／哈萨克斯坦）等区号由多国共享，反向查询会列出全部国家，须结合国家名确认；北美编号计划成员在本表以「1＋地区码」形式收录（如巴哈马 +1242）。
3. 拨号示例为格式演示：拨号格式示例所用号码为占位号段（如 138 0000 0000），仅演示「+区号 本地号」与「00 区号 本地号」两种写法，非真实号码。
4. 只做国家区号查询：本工具只做国家／地区国际电话区号查询，不做号码归属地查询、不做运营商查询；查 IP 归属请用IP 查询，查时区请用时区转换器。
5. 未收录不代表不存在：部分国家／地区（如南极洲等）无公众电话区号，未收录不代表不存在，请以 ITU 公布为准；多米尼加另有 1829／1849、波多黎各另有 1939 备用区号，本表只收主区号。

常见问题

从中国打国际电话，号码前面加什么？
两种写法等价：+区号 本地号（如 +86 138 0000 0000）或 00 区号 本地号（如 0086 138 0000 0000）；手机上直接用 + 写法最方便，座机一般拨 00 开头。
为什么查 +1 会列出好几个国家？
+1 是北美编号计划（NANP）共享区号，美国、加拿大及巴哈马、牙买加等二十多个国家／地区共用 +1，再以地区码区分（如巴哈马 +1242、牙买加 +1876）；本表把美国与加拿大收录为 1，其余 NANP 成员以「1＋地区码」形式收录，反向查 +1 只返回美国与加拿大，查完整区号（如 +1242）可定位到具体国家／地区。
号码解析为什么说「无法识别」？
只有以 + 或 00 开头、且开头为已收录国家区号的号码才能解析；本地号码（如直接以 138 开头）没有国际前缀，本工具不猜测国家，会明示「无法识别」。
这个工具能查手机号归属地或运营商吗？
不能。本工具只做国家区号查询：查 IP 归属请用IP 查询，查时区请用时区转换器，三者分工不同。
我的输入会被上传吗？
不会。搜索、查询、解析、统计与复制全部在本地完成，不发起后端请求；本工具不引入任何第三方库与 CDN，你可以在 DevTools 的 Network 面板验证（除加载本页面资源外无其他请求）。
