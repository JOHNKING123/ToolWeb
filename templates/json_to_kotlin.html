使用说明

                

                    怎么用：把接口返回的 JSON 粘贴到左侧（或点「填充示例」），右侧即刻生成 Kotlin data class；根类名可自定义，两个开关控制注解与可空推断。

                    推断规则：嵌套对象自动拆分为独立 data class（根类在前、按首次出现顺序；同名冲突依次追加 2、3…）；数组→List<T>；空数组→List<Any>；超出 Int 范围的整数→Long；浮点→Double；样本值为 null 的字段→Any?（关闭可空开关则为 Any）；属性名自动转 camelCase，仅当 JSON key 与属性名不一致时才输出 @SerializedName("key")（key 相同时不冗余）；一旦用了注解会自动加上 import com.google.gson.annotations.SerializedName。

                    隐私：纯前端本地处理，JSON 只在你的浏览器里流转，不上传服务器。
                

            

            

                
常见问题

                

                    生成的类名可以改吗？可以，顶部「根类名」输入框改名后输出实时刷新；嵌套类名由其 JSON key 自动转 PascalCase。

                    为什么 null 字段变成了 Any?？样本驱动推断：样本里是 null 就无法知道真实类型，只能退为 Any?，请对照实际 API 文档把类型改具体（见下方真限制①）。

                    注解开关有什么用？默认开启：当 JSON key（如 user_name）与 camelCase 属性名不一致时自动加 @SerializedName，Gson 反序列化才能对上字段；关闭则只输出纯 data class。

                    下载的文件名是什么？「根类名.kt」，例如根类名 User 就下载 User.kt。

真限制说明

                
    
                    
  • 样本驱动推断，请对照 API 文档校对：样本中为 null 的字段只能退为 Any?、空数组只能退为 List<Any>，工具无法凭空知道真实类型，生成后请按实际接口文档把类型改具体。
    • 
                    
  • 复杂结构需人工调整：嵌套泛型、密封类（sealed class）、多态反序列化等超出样本推断能力的结构，生成结果仅作起点，需手动改写。
    • 
                    
  • @SerializedName 面向 Gson：注解与 import 均按 Gson（com.google.gson）生成；使用 Moshi / kotlinx.serialization 的用户请自行替换为对应注解。
    • 
                    
  • 零上传、全部本地：推断与生成全在当前浏览器内完成，JSON 不上传任何服务器；本页面不发起任何外部网络请求。
