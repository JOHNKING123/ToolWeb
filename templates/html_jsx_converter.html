粘贴 HTML/SVG 源码，词法级转成 React JSX：属性映射、自闭合、style 对象化一次到位

文本不出浏览器：全部转换都在本机完成，本页面不发起任何网络请求、不上传任何输入（零 fetch / XHR），粘贴的源码只留在当前页面。
真限制（请先看清再用）：

1. 只做词法级转换，不做语义校验：本工具只按字面改写标签与属性，不检查标签是否配对合理、不校验 JSX 语义，转换结果需在你的项目里编译验证，报错请按编译器提示修正。

2. 不解析 JS 表达式：事件属性（如 onclick）与花括号表达式不做转换，原样保留并列入报告；需要 onClick 请在项目里手工改写。

3. 不承诺自定义属性全覆盖：映射表只覆盖常用属性与 SVG camelCase，未知属性原样保留并列清单，请核对报告再决定是否手工改名。

4. style 只做字面转换，不补单位、不展开简写：style="color: red; font-size: 14px" 转成 style={ {color: 'red', fontSize: '14px'} }，不补 px、不把 margin 简写拆成四边，简写请在项目里自行展开。

5. 不读用户项目文件：本工具只转粘贴进来的源码，不读取、不扫描你本地项目里的任何文件，组件名与导入请自行补齐。

6. 不处理服务端渲染与样式文件：class 名只改写属性名，不改 CSS 文件、不生成 CSS Modules 映射，样式文件请自行对应。

使用说明

  1. 把 HTML 或 SVG 源码粘贴到输入框，按需开关 5 项规则，点「转换为 JSX」。
  2. 属性映射：class→className、for→htmlFor、tabindex→tabIndex、colspan→colSpan、stroke-width→strokeWidth、fill-rule→fillRule、clip-path→clipPath、xlink:href→xlinkHref 等常用映射一次改写。
  3. 结构处理：br / img / input 等 void 标签自动自闭合；未闭合的 SVG 形状（如 path）无子节点时也自动自闭合，否则 JSX 无法编译。
  4. 内联样式：style="color: red; font-size: 14px" 转成 style={ {color: 'red', fontSize: '14px'} }，只做字面转换，不补单位、不展开简写。
  5. 注释与布尔属性：HTML 注释转成 {/* */}；checked、disabled 等布尔属性保留无值形式。
  6. 输出模式：片段模式只输出 JSX 片段；组件模式包一层 export default function 组件名()，组件名须为合法标识符且首字母大写，非法会报错。
  7. 看「转换报告」核对：映射、自闭合、style、注释、原样保留五项计数与清单，开关关闭后对应项同步归零。
  8. 点「复制 JSX」或「下载 .jsx 文件」导出；点示例一键载入 3 组典型源码（请按需改写），载入后仍可编辑再转换。

常见问题

转换完直接粘进项目就能跑吗？
不一定。本工具只做词法级转换，不做语义校验，转换结果需在你的项目里编译验证；编译器报错（如未闭合标签、表达式问题）请按提示修正。
为什么我的 onclick 没有变成 onClick？
因为事件属性的值是 JS 表达式，本工具不解析 JS 表达式，故原样保留并列入报告；需要 onClick 请在项目里把字符串改成花括号表达式。
自定义属性为什么没改名？
映射表只覆盖常用属性与 SVG camelCase，不承诺自定义属性全覆盖；未知属性原样保留并列在报告清单里，请核对后手工改名。
style 里的 margin 简写为什么没展开？
style 只做字面转换，不补单位、不展开简写；简写属性在 React 内联样式里同样是简写，需要展开请在项目里自行处理。
组件名为什么报错？
组件模式要求组件名是合法标识符且首字母大写：数字开头、含连字符、小写开头都会报错；改成如 MyCard 后再转换。
我的源码会被上传吗？
不会。全部转换在浏览器本地完成，零网络请求，输入只留在当前页面；本工具也不读用户项目文件。
