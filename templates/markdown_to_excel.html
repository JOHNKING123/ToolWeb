表格预览（请先核对）

导出文件：列宽按内容自动调整；千分位数字与百分比存为真实数值（可直接求和；百分比打开后显示为小数，选中列设为「百分比」格式即恢复）；15 位以上长 ID 与前导零存为文本（防科学计数法）。注：所用 SheetJS 社区版不支持写单元格样式，表头加粗/底色、首行冻结、0.00% 数字格式在导出的文件中不生效。

使用说明

怎么用：把 ChatGPT / Claude / DeepSeek 等 AI 回答（含 Markdown 表格）整段粘贴进来，或上传 .md 文件 → 点「解析表格」→ 在预览卡片里核对表数、表头与统计 → 点「导出 .xlsx」下载（多张表格自动分成多个工作表）。
表名规则：每张表格取其上方最近的 #/## 标题做 sheet 名；无标题用「表格1/2/3」；非法字符（\ / ? * [ ] :）替换为下划线、超 31 字符自动截断、重名自动加 _2 后缀。
单元格类型：1,234,567.89 这类千分位数字、12.5% 这类百分比存为真实数值（百分比按小数存储，如 12.5% 存为 0.125，可直接求和/画图；在 Excel 里选中该列设为「百分比」格式即显示为 12.50%）；15 位以上长数字 ID（如订单号 20260118000123456）与前导零编号（如 00123）存为文本，Excel 打开不会变成科学计数法丢精度。
单表复制：每张预览卡片右上角「复制 TSV」，可直接粘贴进 Excel / WPS，不挤列。
转义竖线：单元格里的 \| 会还原为 |，不会被误切成两列；行内 **加粗**、`代码`、[链接](url) 等 Markdown 修饰会被清理成纯文本。
隐私：解析与导出全程在你的浏览器里完成，文本只在浏览器内存里流转，不经过任何服务器；SheetJS 库从 CDN 懒加载（失败时自动走本站本地副本），你的数据不会发给 CDN。
适用边界（如实说明）：没有 --- 分隔行的表格识别不了；表格里的合并单元格会被展开成普通单元格；超大文本（几十万字符）解析可能需要几秒，属正常。
「AI 写作→办公」组合：粘贴 AI 文本前，先用 AI 文本清洁器 清掉零宽字符等看不见的杂质，用 AI Token 计数器 估算发给大模型的 token 数与费用；回答里的表格，回到本页一键转成 .xlsx —— 清杂质、算用量、转表格，一套流程走完。
