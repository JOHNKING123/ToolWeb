calculate 单位感知记事本计算器

像写记事本一样写算式：每行一个表达式，右侧行内即时显示结果。带单位感知——长度、重量、体积、时间、温度（℃↔℉）、货币自动换算，加减自动归一化到最先出现的单位；支持行间变量、百分比、sum(a1..a3) 范围汇总，底部按维度分组给出求和 / 平均 / 最大值 / 最小值 / 计数。自写词法解析（零 eval），纯前端零上传。

help_outline 使用说明

基本写法
每行写一个算式，支持 + - * /、括号、%：5kg * 3 → 15 kg；(长 + 宽) * 2。非法行行内标红，不中断其余行。
单位换算与归一化
加减时结果自动归一化到最先出现的单位：10km + 500m → 10.5 km；500m + 10km → 10500 m。乘除会派生复合单位：2m * 3m → 6 m²，10km / 2h → 5 km/h。
维度支持的单位
长度km（千米/公里）、m（米）、cm（厘米/公分）、mm（毫米）、in（英寸）、ft（英尺）、mi（英里）
重量t（吨）、kg（千克/公斤）、g（克）、斤、lb（磅）、oz（盎司）
体积m³（立方米）、L（升）、mL（毫升）、gal（加仑）
时间d（天）、h（小时）、min（分钟）、s（秒）
温度°C（C/℃/摄氏度）、°F（F/℉/华氏度）、K（开尔文）
货币¥（￥）、$、€ —— 仅为标签，不参与换算
单位转换
用 to 或 ->：25C to F → 77°F；10km -> m → 10000 m；3斤 to g → 1500 g。
行间变量
用 = 赋值，变量名可用中英文：total = 5kg * 3，后续行直接写 total / 2。to / of 是保留字，不能做变量名。
百分比
5% of 200 → 10；200 + 5% → 210（加价 5%）；200 - 5% → 190；200 * 1.05 → 210。
范围汇总
sum(a1..a3) / avg / max / min / count：对 a1、a2、a3 三个已赋值变量汇总；也支持逗号写法 sum(p1, p2, p3)。
货币说明
¥ / $ / € 写在数字前后均可（¥100、100$），结果保留原符号；不同货币不能相加，货币不参与单位换算。
注释
# 或 // 之后的内容当注释忽略，方便给算式加备注。
已知限制
数字后紧跟的字母会被识别为单位（如 5m 是 5 米），变量与数字相乘请写 5 * m；概率分布 / 蒙特卡洛模拟为二期规划，本期暂不提供。
