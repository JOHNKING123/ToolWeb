menu_book 使用说明

  1. 用取色器选基色，或直接输入 HEX（如 #2563EB），或点「随机基色」碰运气。
  2. 6 种方案同时展开对照：互补（+180°）、类比（±30°）、三角色（+120°/+240°）、分裂互补（+150°/+210°）、四方形（+90°/+180°/+270°）、单色（同色相 6 档明度阶梯）。
  3. 点击任意色板复制该色 HEX；每方案下方可一键复制整方案 HEX 列表或 CSS 变量（:root { --palette-1: … }），直接粘贴进样式表。
  4. 每色下方标注与白底、黑底的 WCAG 对比度数值与 AA 标识：AA 要求普通文本 ≥ 4.5:1，AAA ≥ 7:1，3:1–4.5:1 仅大文本可用。

quiz 常见问题

6 种方案的角度是怎么定的？
以 HSL 色轮为准：互补取对面 180°，类比取左右 ±30°，三角色互隔 120°，分裂互补取互补色两侧 ±30°（即 +150°/+210°），四方形互隔 90°，单色不换色相、只拉明度阶梯。色相超出 0–360° 时按取模回绕。
为什么有的方案颜色看起来很接近？
基色饱和度低（接近灰）时，换色相也看不出差别；单色方案本就是同色相阶梯。想要拉开差距，先把基色饱和度调高，或换一个更鲜艳的基色。
对比度数值准吗？
按 WCAG 相对亮度公式计算（sRGB 线性化后 0.2126/0.7152/0.0722 加权），与手工计算一致；AA 标识只看数值是否 ≥ 4.5:1，不做「可直接商用」之类的绝对承诺。
复制按钮没反应怎么办？
一键复制需要浏览器剪贴板权限；被拒绝或不支持时会自动降级为选中复制，仍失败会明确提示手动复制，HEX 文本本身就在色板上可见。
我的基色会上传吗？
不会。所有计算在浏览器本地完成，本页面不发起网络请求，可用 DevTools 的 Network 面板验证。
