使用说明

  1. 上传截图：点击上方虚线框选择 PNG / JPG / WebP（≤20MB），或直接拖拽进来；也可以点「载入示例截图」先体验。
  2. 选场景调参数：左侧选浏览器窗口框 / 手机机身框 / 悬浮 3D 卡片 / 平面阴影，拖动滑杆实时调整 3D 旋转角度、透视距离、缩放、背景、阴影强度、倒影与机身框颜色。
  3. 导出：右侧选导出尺寸（原图 / 2x 高清 / 长边 1920），确认「实际导出像素」后点「下载 PNG」。

能力边界（真限制）

  • 机身框为自绘 CSS / canvas 绘制，非真实设备照片级还原，不做材质纹理与光影细节。
  • 导出分辨率上限：长边 4096px，超大截图会自动降采样，并如实明示实际导出像素。
  • PNG 为无损导出、体积较大（不做 JPEG / WebP 有损压缩以保画质），体积敏感可去图片压缩再压。
  • 全程浏览器本地处理，图片零上传：截图只在你的浏览器内存里流转，不会发送到任何服务器。
