图片取色器与主色提取

上传本地图片，点击任意像素取色；4 倍放大镜精确定位；一键提取主色，导出 HEX 列表或 CSS 变量。

真限制，先说清楚：① 只读本地上传图片，不做 URL 抓取——外链图片请先下载到本地再上传；② 取色精度受压缩与抗锯齿影响，边缘像素仅供参考，以纯色区域取色为准；③ 透明像素说明：alpha 小于 255 时会同时显示 RGBA 值，透明像素的 RGB 仅为底色混合参考；④ GIF 只取首帧，动图不逐帧取色；⑤ 主色提取为量化近似：中位切分结果是统计主色，不是精确的品牌标准色值；⑥ 不收集、不上传任何内容：读图与取色只在浏览器本地完成（canvas getImageData），本页面不发起任何网络请求。

使用说明

取色：上传图片后直接点击图片，当前像素的 HEX／RGB／HSL／CMYK 与坐标会同步显示；鼠标悬停时放大镜帮助精确定位。
主色：用滑杆选 1–10 个主色，点「提取主色」，中位切分量化按像素占比降序给出色板。
导出：HEX 列表为换行分隔的小写 HEX；CSS 变量为 --color-1、--color-2……逐行变量，可复制或下载 palette.txt／palette.css。
隐私：所有读图、取色、量化、导出都在浏览器本地完成，不收集、不上传任何内容。

常见问题

为什么不能粘贴图片链接取色？
本工具只读本地上传图片，不做 URL 抓取——外链图片受跨域（CORS）限制，浏览器不允许直接读取像素。请先把图片下载到本地再上传。
取到的颜色和品牌标准色有偏差怎么办？
压缩失真与抗锯齿会让边缘像素偏离标准色，边缘像素仅供参考；请在纯色区域中心取色，并以主色提取的统计结果交叉核对。
透明图片取色怎么看？
alpha 小于 255 的像素会显示 alpha 值并提示：透明像素的 RGB 仅为底色混合参考，不能直接当作不透明色使用。
GIF 动图取色取哪一帧？
只取首帧，动图不逐帧取色。
主色就是图片的精确品牌色吗？
不是。主色提取为量化近似：中位切分是对抽样像素的统计归纳，适合快速得到配色方向，精确色值仍以纯色区域取色为准。
图片会上传到服务器吗？
不会。读图走 FileReader＋Image＋canvas getImageData，只在浏览器本地完成，不收集、不上传，本页面无后端调用、无外部请求。
